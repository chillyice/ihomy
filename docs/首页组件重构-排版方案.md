# 首页组件重构 — 排版方案

> 本文是「首页组件重构」的正式设计方案，由苏格拉底式探询（详见 `docs/首页组件重构-设计探询记录.md`）收敛而来。探询记录是问答过程存档；本文件是**待实现的方案结论**，实现前以此为准。

## 一、设计目标（从探询提炼）

1. 解决「内容太浅太薄」三宗罪：大组件很空、信息被藏、空壳占位太多。
2. 默认态「不挤不空、有留白、温暖」——不密密麻麻淹没，也不冷冷清清。
3. 让首页「详略得当」：默认一眼速览核心信息，hover 展开补内容；不是把所有深度都堆在首屏，也不藏到要点进去才看得到。

## 二、核心交互范式

### 2.1 尺寸体系（四档 + hover 两套并存）

| 概念 | 定义 |
|------|------|
| **四档**（巨大/大/中/小） | 组件「永久摆放尺寸」，由用户**拖拽 snap** 到预设档位决定；每档内部排版不同（渐进展开） |
| **hover 放大** | 另一套**临时**预览：悬停时组件临时升档补内容，移走复原 |

- 废弃自由拖拽缩放 → 改为**拖拽 snap 四档**（拖到接近某档吸附）。
- **只有中小档 hover 才放大**；大/巨大档已够大，hover 不再放大。
- hover 触发加**悬停延迟（~300-400ms）**，防扫视抖动。

### 2.2 hover「推开邻居」动效

- 悬停的组件放大展示更多；周围组件**缩小成「图标 + 标题」胶囊**（内容区隐藏）。
- 邻居**不是真实重排**，只做 `transform` 视觉位移（看起来被「挤」到缩小后的位置），不触发 grid reflow。
- 追求「油膜上滴洗洁精」/「鲜花绽开挤开绿叶」的美感。
- 小组件（小档）在未展开时用**波浪/文字提示**引导用户「hover 查看更多」。

### 2.3 触摸/平板范围（首版）

- **桌面 hover 优先**。触摸/平板只展示默认「详略得当」布局，点组件进对应页面，不做展开。
- tap 展开作为后续独立迭代（需另行设计触摸手势，避免与「点击跳转」冲突）。

## 四、各组件四档内容增量（渐进展开）

> 规则：**小档=一眼核心**；**中档=默认详略得当**；**大档=完整内容**；**巨大档=扩展内容**。hover 放大时，组件从当前档临时升一档展示（小→中→大）。大/巨大档不参与 hover 放大。

### 4.1 feed 家人动态（信息型）
| 档 | 内容 |
|----|------|
| 小 | 最新 2 条动态（头像+昵称+摘要一行） |
| 中 | 最新 4 条（头像+昵称+气泡摘要+相对时间） |
| 大 | 最新 6-8 条，带类型标签+完整摘要 |
| 巨大 | 分类型 tab（博客/日记/照片/视频/任务/菜谱/书架）+ 各自列表 |

### 4.2 album 相册（信息型）
| 档 | 内容 |
|----|------|
| 小 | 家庭相册封面（4:3 封面卡片，展示「家庭相册」） |
| 中 | 3-4 张拍立得散开堆叠 |
| 大 | 5-7 张拍立得散开堆叠，**hover 触发横版翻牌播放**（像真实相册翻页，翻过去淡出、露下一张，每张约 2s） |
| 巨大 | 更多拍立得散开 + hover 翻牌播放 |
> 点击照片 → 进相册页 `/album`（不进 PhotoViewer）。

### 4.3 search 找物（工具型，含户型图）
| 档 | 内容 |
|----|------|
| 小 | 仅搜索框（hover 显示同大档效果） |
| 中 | 搜索框 + 户型图小缩略图 |
| 大 | 搜索框 + 语音输入按钮 + 只读户型图（`FloorPlanCanvas` 查看态），搜索后 hover 展示物品位置+命中列表 |
| 巨大 | 同上，户型图更大、物品列表更全 |
> 数据：复用 `itemApi.floorPlan(houseId, floor)`；只读，不加编辑、不加列表 tab。点击结果 → `/item` 定位物品。

### 4.4 weather 天气（信息型，AI 底图）
| 档 | 内容 |

| 小 | 天气图标 + 当前温度 |

| 大 | 中档基础上 + 未来 3 天预报 |
| 巨大 | + 未来 7 天预报 |

## 六、实现要点（与现有代码的差异）

1. **删音乐组件**：从 `Home.vue` 模板 + `DEFAULT_LAYOUT` + `WIDGET_LABELS` + 侧边栏组件池移除 `music`；保留悬浮 `MusicPlayer.vue`。
2. **四档 snap**：`onResizeStart/onMouseMove` 由自由缩放改为吸附到 {2×2, 3×3, 4×4, 5×5}（可横向 5×4/6×4）档位。
3. **拖出默认尺寸**：`onDrop` 里 `w:4, h:5` 改为按 `WIDGET_DEFAULT_SIZE[type]` 查表。
4. **hover 放大**：新增悬停状态机（延迟触发 + 仅中小档）；放大时邻居 `transform` 缩放成胶囊 + 视觉位移。
5. **渐进展开内容**：各组件模板按当前档位渲染不同内容块（`w.h`/档位驱动 `v-if` 分支）。
6. **找物户型图**：引入 `itemApi.floorPlan` + 只读 `FloorPlanCanvas`（`mode='view'`）。
7. **天气 AI 底图**：接入生图（复用 `AiService`/IMAGE 能力 + `chatJson` 走 `ThirdPartyHttp`），分组缓存 key=`{city,weather,dayNight,season}`，TTL 7 天；无 AI 回落渐变+毛玻璃。
8. **相册翻牌播放**：hover 态新增翻牌动画（页面翻转 + 淡出 + 下一张，~2s/张）。

## 七、分阶段实施

| 阶段 | 内容 | 风险 |
|------|------|------|
| P0 | 删音乐格子 + 拖出默认尺寸查表 + 四档 snap | 低 |
| P1 | 渐进展开（各组件按档渲染）+ 默认布局重排 | 中 |
| P2 | hover 放大 + 推开邻居动效 + 波浪引导 | 高（动效） |
| P3 | 找物户型图 + 相册翻牌播放 + 天气 AI 底图 | 高（跨模块数据/生图） |
| 后续 | 触摸 tap 展开 | 高（手势设计） |

> 每阶段完成后可独立验收；P2/P3 建议单独做视觉验收（动效观感需实际渲染确认）。
