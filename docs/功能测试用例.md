# ihomy 功能测试用例集

> 版本：V1.0（2026-09-06）　依据：`backend` 源码（Controller/Service/DTO）、`schema.sql`、`docs/需求设计说明书.md`、前端 `frontend/src/views`
> 范围：手工功能测试（黑盒），不含自动化脚本与性能/安全专项测试（安全项仅覆盖功能层面的注入/越权冒烟）
> 用例总数与优先级分布见文末「附录 A 用例统计」。

## 0.1 测试环境与账号矩阵

| 代号 | 说明 |
|------|------|
| OWNER-A | 家庭 A 创建者（家长），拥有家庭 A 全部权限 |
| MEMBER-A / CHILD-A / GUEST-A | 家庭 A 普通成员 / 儿童 / 访客 |
| OWNER-B | 家庭 B 创建者，与家庭 A 无交集 |
| OPS | 纯运维账号（仅 OPS 角色，不属于任何家庭） |
| 游客 | 未登录浏览器会话 |

- 测试地址：开发环境 `http://localhost:5173`（前端 dev，代理 `/api` → 8080）。
- 开发环境图形验证码固定为 `qwer`；**凡涉及验证码过期/一次性/错误码的用例，需临时在 external.yml 清空 `app.captcha-fixed-code` 走真实验证码**，或直调接口验证。
- 响应统一结构 `{code, message, data}`；常用业务码：400 参数错误 / 401 未登录 / 403 无权限 / 404 不存在 / 409 冲突 / 1003 密码错误 / 1005 邮箱已被注册 / 1006 验证码错误或已过期 / 1007 今日已签到 / 1008 积分不足 / 1009 商品已售罄。
- 字段「测试类型」取值：正向 / 等价类 / 边界值 / 异常输入 / 状态流转 / 交叉 / 中断 / 重复 / 权限 / 安全。
- 标注「⚠探缺陷」的用例：代码走查发现当前实现可能不符合预期，执行时按实际结果记录缺陷或确认现状。

### 33.2 容易遗漏的测试点清单

1. **时区与跨天边界**：签到日期归属（23:59/00:01）、提醒 5 分钟扫描窗口的到点前/后、纪念日倒计时、记账 month 月末（PT-005、REM-002、ANN-001、BOOK-001）——注意服务器时区与浏览器时区不一致的情况。
2. **农历/特殊日期**：农历闰月年、公历 2 月 29 生日、春节前后跨年纪念日（ANN-002/003）。
3. **操作中断类**：上传中途断网/取消（ALB-007、VID-008）、博客/日记编辑页直接刷新**草稿是否丢失**（当前未发现草稿自动保存，建议补确认）、批量操作部分失败的反馈（LIB-007 吞错无汇总）。
4. **重复提交类**：双击提交、浏览器返回后重复提交表单、F5 重放 POST（COMM-008、LIKE-005、CMT 各写接口）。
5. **并发场景**：同一账号双端同时登录并各自切换家庭/改资料；WebSocket 多端同时在线的消息顺序；积分兑换与签到同时发生时余额快照。
6. **缓存失效验证法**：改角色/切家庭/移出成员后**不要重新登录**，直接刷新页面验证权限即时性（MEM-008/011、AUTH-022）——5min TTL 会掩盖失效遗漏。
7. **软删 vs 硬删混淆**：博客/日记/评论为软删，照片/相册/视频/图书为物理删——验证已删内容的点赞数、评论列表、瀑布流、动态流是否仍统计已删内容（孤儿计数）。
8. **文件系统层验证**：删照片/视频/图书后不仅查接口，要**登服务器看 uploads 目录**确认文件与缩略图真删（FileService 失败仅告警不抛错，孤儿文件静默产生）。
9. **文件名与 URL**：同名文件覆盖（时间戳前缀应规避）、超长文件名、纯扩展名文件、文件名含 `../`、`/files/` 目录无列表遍历（nginx）。
10. **LIKE 通配符**：关键字搜索输入 `%`、`_`、`'`（模糊查询转义）。
11. **游客视角全链路回归**：整理白名单接口清单（/auth、/public、/home/modules、file-signed、/ws 握手），逐一验证未登录行为——防止新接口误挂白名单。
12. **GUEST/CHILD 最小权限回归**：权限种子（sys_auth/sys_role_auth）遗漏新接口会 403，或漏拦会放权——新增功能后必须全角色点一遍（COMM-003、OPS-002）。
13. **多标签页/多端覆盖丢失**：两人同时编辑同一篇博客/同一个计划（后写覆盖先写，无乐观锁）。
14. **通知边界**：receiver 被移出家庭后历史通知是否仍可见；read-all 与新通知到达并发时的未读数。
15. **商品/订单状态组合**：兑换后商品被软下架/删除，订单核销是否正常（订单存快照，理论上正常——需实测）。
16. **头像/封面孤儿文件**：重复更换头像/家庭封面/相册封面，旧文件是否清理（当前仅相册封面更换会删旧文件，头像/家庭封面成孤儿）。
17. **大数据量回归**：千张照片瀑布流（`ORDER BY RAND()` 性能）、聊天历史 200 条 clamp、日志表 10 万行的运维分页查询。
18. **PWA 升级**：前端发版后旧 Service Worker 缓存脏页面——版本更新后强制刷新验证。
19. **邮箱大小写**：大写邮箱登录（注册统一转小写）、注册页邮箱前后空格。
20. **深色模式 + i18n 组合**：后端返回的中文错误 message 不随语言切换（当前固定中文），确认前端展示策略。
21. **被动触发类功能的时间验证**：提醒夜间静默（23:00-06:00）、天气预警 30 分钟轮询、每日一图跨天缓存——这类「定时任务」用例需等待或调整系统时间，容易被跳过。
22. **operation 日志完整性**：所有写接口（POST/PUT/DELETE）在 sys_operation_log 有记录且 result/耗时正确（抽验即可，防止新接口漏加 @OperationLog）。
