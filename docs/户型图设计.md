# 物品定位 · 户型图功能设计(计划 v4)

> 状态:设计已冻结,待开工(开发分支 `item_seeker`,未合 main)。
> 本文是「物品定位-户型图」(P2 待办)的完整设计,所有决策经与用户逐条确认后定稿,开工前如无新需求不再改动。

## 0. 目标与边界

家庭内「找东西」的**示意级**户型图:正交多边形房间 + 矩形家具 + 物品点,三层同一张画布,可拖拽编辑、可吸附、可标定比例、可数值输入精确尺寸。

**页面 = 户型图主视图(不是 tab)**:物品定位页整个主体就是画布,不加独立导航。顶部常驻搜索框 + 房子/楼层切换 + 「列表/编辑」按钮;空态时画布中央大「+」提示加房子。

**两模式分离(核心)**:「查看/找东西模式」与「编辑模式」严格分开。
- 查看/找东西(默认):顶部搜索框 → 下方户型图标注物品位置,形成「搜东西 → 看在哪」闭环。
- 编辑:点「编辑」才进入,画房间/摆家具/放物品/上传底图/标定;点「完成」退出。

**徒手画 = 一等公民**:底图只是可选辅助。不是人人都有户型图,没有底图也要画得舒服。

**编辑器不做半成品**:户型图一次画好长期用,但家具位置会变、可能要画多张图;编辑能力必须完整好用,不能偷懒。

**不做**:斜墙/圆弧墙、共享墙实体、墙厚建模、门窗符号、内置家具真实尺寸库(逐件录入真实尺寸可以)、CAD(DXF/DWG)导入、建筑规范级面积核算、多人实时同屏。

## 1. 数据模型(定死)

### 1.1 房间 = 正交多边形(替换矩形)

`family_room` 删除 `x/y/w/h`,新增 `geometry TEXT`(JSON 有序顶点数组):

```json
[{"x":0,"y":0},{"x":300,"y":0},{"x":300,"y":200},
 {"x":100,"y":200},{"x":100,"y":400},{"x":0,"y":400}]
```

- 边只允许横/竖(正交),矩形 = 4 个顶点,是特例。
- 顶点 ≥ 4,闭合;缺口/L 形/T 形都是同一份多边形数据,无「缺口列表」补丁结构。

### 1.2 家具 = 矩形 + 类型 + 自定义命名 + 家具库

`family_furniture` 新增:
- `x / y / w / h`(DECIMAL,可空 = 尚未摆上户型图)。
- `type`(VARCHAR,预设类型清单 + 可自定义):衣柜/床/冰箱/书桌/沙发/茶几/柜子/餐桌/书架/其他。类型给图标。
- `name`(已有,自定义命名,如「主卧衣柜」「床1」):区分同种家具,自由填。
- `room_id` 可空 = 家具在「家具库」(未分配房间)。**删房间时家具进库(room_id 置空)、与物品的绑定(`furniture_id`)不动**,新房间建好后从库拖回。圆形家具不做。

### 1.3 物品 = 锚点 + 相对坐标 + 位置描述(无抽屉层级)

`family_item`:
- `furniture_id` 非空 → 物品锚在**家具**上,`rel_x/rel_y` 为家具包围盒内 0~1 相对位置。
- `furniture_id` 空(散放)→ 物品锚在**房间**上,`rel_x/rel_y` 为房间包围盒内 0~1 相对位置。
- `position`(文本,已有)承载精确定位描述,如「第三层左侧抽屉」——定位到某家具后,一个文本字段描述即可,**不建抽屉/隔层层级**。

### 1.4 墙 = 房间之间的空隙,无实体

墙厚 = 两房间多边形之间的空隙;不建墙实体,不量厚度。

### 1.5 楼层配置(底图 + 比例尺按楼层,默认 100px/m)

`family_house` 删除单值 `plan_image_url / plan_scale`,新增 `floor_plans TEXT`(JSON,key=楼层号):

```json
{"1":{"imageUrl":"/files/x.jpg","scale":100.0},"2":{"imageUrl":"/files/y.jpg","scale":100.0}}
```

- 楼层列表 = `floor_plans` 的 key ∪ `room.floor`;「加楼层」= 加一个 key。
- 每楼层独立底图 + 比例尺;楼层 label 由数字派生(`1`→「1楼」,`-1`→「地下1层」)。
- **默认 `scale = 100px/m`**(非空):160㎡ 房子 ≈ 13m ≈ 1300px,加载时自动缩放到一屏。
- **标定 = 可选校正**:有底图时两点测距校正 scale;无底图直接用默认值画,不是前置必须。
- 不加 `family_floor` 表(避免表数膨胀);将来需要楼层名/排序时再升级为表。

## 2. 坐标系

- 每「房子 × 楼层」一张画布,单一像素坐标系。
- 三层同坐标系:房间(多边形)、家具(矩形)、物品(点,由锚点换算成绝对坐标)。
- 底图与比例尺按楼层存(`family_house.floor_plans`),底图铺在原点;`scale`(像素/米)默认 `100px/m`,标定后校正,用于尺寸显示。

## 3. 家具随房间移动规则(用户确认)

- **房间整体平移** → 家具跟随(级联平移)。
- **房间变形(拖边/角)** → 家具原地不动、不缩放、不变形。
- 例:靠墙橱柜,后墙被移动时,橱柜不动,只有墙变位置。
- 实现:家具存画布绝对坐标;房间平移时对归属该房间的家具级联平移同 delta,变形时不做任何级联。

## 4. 渲染:SVG,手绘草图风

- 房间 = `<polygon>`,家具 = `<rect>`,物品 = `<g>`。
- **视觉 = 手绘草图风**(铅笔线条感),契合现有暖棕毛玻璃主题。
- 选型理由:房间模型即正交多边形,SVG 的 polygon 与之 1:1;顶点手柄、边中点手柄、点选判定、吸附距离、尺寸线全内置;对象数量(几十个)远低于 canvas 优势阈值。
- 不用 div+clip-path(缺口多边形丑、点选手写)、不用 canvas(点选/文字/样式全手写)、不引 fabric/Konva(多边形顶点编辑是弱项,加依赖)。

## 5. 模式与页面布局(用户确认)

### 5.1 两种模式

- **查看/找东西模式(默认)**:顶部搜索框 + 户型图主体;搜物品 → 画布放大高亮位置。
- **编辑模式**:点「编辑」进入,左侧出酷家乐式侧栏,画房间/摆家具/放物品/上传底图/标定;点「完成」退出。
- 切换显式,避免查看时误拖。

### 5.2 桌面页面布局

```
┌──────────────────────────────────────────────────────────────┐
│  [房子▾]          [🔍 搜索物品名称……]            [列表] [编辑] │
├──────────────────────────────────────────────────────────────┤
│  ┌─────────┐                                                 │
│  │ 编辑侧栏 │         户型图画布(SVG, 手绘草图风)              │
│  │ 房间     │                                                 │
│  │ 家具     │                                ┌─────────────┐ │
│  │ 库       │                                │ 搜索命中     │ │
│  └─────────┘                                │ 剪子 ×3     │ │
│                                             │✓书房书桌…   │ │
│  ┌─────┐                                    │ 主卧梳妆…   │ │
│  │ 3F  │ ← 楼层切换(左下角,商厦模式)          │ 次卧柜子…  │ │
│  │ 2F  │                                    └─────────────┘ │
│  │ 1F  │                                                   │
│  └─────┘                                                   │
└──────────────────────────────────────────────────────────────┘
```

- **顶栏常驻**:房子下拉(6 套房主切换)+ 搜索框 + 「列表」「编辑」按钮。
- **左下角楼层切换器**:竖排 `1F/2F/3F`,当前层高亮(商厦电梯地图惯例);**没画户型图的房子不显示、默认 1F**。
- **搜索命中**:右下角弹结果列表(所有命中,按房子/楼层/位置分组),当前画布展示的那几把在列表里显著加亮;点某条 → 自动切房/楼层 + 画布高亮。
- **编辑态左侧侧栏(酷家乐式)**:子 tab「房间 / 家具 / 库」,拖拽/点击素材到画布;**查看态隐藏**。
- **空状态**:无房子时画布中央大「+」→ 建房子。
- **查看态(默认)**:每次进来直接看户型图;物品标记**不常显**,搜索命中或点家具才浮现。
- **列表**:切到旧方式房子/房间/家具/物品 CRUD。

### 5.3 加数据的两种方式(并存)

- **旧方式(列表)**:点「列表」→ 房子/房间/家具/物品 CRUD,不画户型图也能用。
- **画布方式(编辑态)**:画完/摆完弹窗命名,一步建好实体 + 几何;或从编辑侧栏(房间/家具/库)拖入画布。
- **家具库**:删房间后家具进库(room_id 空),从编辑侧栏「库」子 tab 拖回新房间。

### 5.4 移动端

- **只读户型图** + 搜索定位(能看、能找)。
- **可增删改房子/房间/家具/物品**(列表 CRUD)。
- **不做画布编辑**(编辑户型图桌面专属)。

## 6. 编辑手势(9 个必须 + 2 个创建/定位,仅编辑态生效)

| 手势 | 效果 |
|------|------|
| 拖房间主体 | 全顶点平移 |
| 拖房间顶点 | 移动单个角(四角、缺口角通用) |
| 拖房间边中点 | 整条边平移(相邻两点跟随,保持直角) |
| 双击房间边 | 插入新顶点(造缺口) |
| 双击房间顶点 | 删除该顶点(去缺口,最少 4 点) |
| 拖家具主体 | 移动家具 |
| 拖家具边/角 | 缩放家具 |
| 拖物品标记 | 锚点内定位 |
| 空白拖拽/滚轮 | 平移/缩放画布 |
| 拖拽拉矩形 / 点击逐点描绘 | 画房间(逐点描绘双击闭合,直接画 L 形/缺口) |
| 定位模式 | 物品搜索/列表「定位」跳转画布,放大居中高亮该物品 |

## 7. 吸附规则

- 不建共享墙,两房间独立;拖靠拢一侧的边只动被拖房间,邻居不动。
- 磁吸:边对边、顶点对顶点,阈值 ~6px,吸附时显示对齐虚线提示。
- 家具同理:家具边吸附房间边/其他家具边(贴墙摆放柜子)。

## 8. 尺寸标注与数值输入(用户确认)

- **边长常显开关**:开 = 所有边常显米数;关 = 拖动时只显示「受影响的边」。
  - 拖角 → 显示该角的两条边。
  - 拖边 → 显示该边的两条相邻边(拖边本身长度不变,变的是相邻边)。
- **数值输入**:选中边/角,键入精确米数(精确到毫米 = 3 位小数,如 `3.250`),程序换算像素。
- 拖拽 = 大概定型,数值输入 = 雕刻。
- 默认 `100px/m` 即显示米数;标定后更准,不是「未标定不显示」。

## 9. 底图标定与房间面积

- **底图**(可选辅助,按楼层):上传当前楼层户型图图片铺作底图,两点测距输入实际米数 → 校正该楼层 `scale`。
- **房间面积**(附带):多边形面积公式(shoelace),显示 `xx.xx m²`。

## 10. 后端接口

| 接口 | 说明 |
|------|------|
| `GET /item/floor-plan?houseId=&floor=` | 一次返回 house 元信息(该楼层底图/比例尺)+ rooms(几何)+ furnitures(几何+type)+ items(锚点/相对坐标/position) |
| `PUT /item/house/{id}/floor-plans` | 保存楼层配置 JSON(底图上传/移除、比例尺校正、加楼层) |
| `PUT /item/room/{id}/geometry` | 保存房间多边形(替代原 `room/{id}/plan`) |
| `PUT /item/furniture/{id}/geometry` | 保存家具矩形 + type(新增) |
| `PUT /item/{id}/place` | 物品相对坐标(保留) |
| 房/家具/物品 CRUD | 保留,仅增字段 |
| `GET /item/furniture?roomId=`(空) | 家具库列表(编辑侧栏「库」子 tab);`room_id` 空 = 在库 |

> 搜索无独立接口:走 `GET /item/list`(全字段)+ 前端按名称过滤;命中项的 `furniture_id → room → floor` 联动 `floor-plan` 定位高亮。

## 11. 分期(用户授权由我定)

- **S1 数据模型重构**:schema + 后端全改 + migration(存量 `x/y/w/h` → 4 点多边形;`plan_image_url/plan_scale` → `floor_plans` JSON;家具加 `type`)。这一关过了才不屎山。
- **S2 页面骨架 + 编辑手势**:主视图 + 查看/编辑两模式 + 空态「+」+ 搜索框 + 列表入口 + 左下角楼层切换器 + 编辑侧栏(房间/家具/库);SVG 渲染 + 顶点/边/主体拖动 + 双击加点/删点 + 家具拖拽缩放 + 逐点描绘。
- **S3 吸附**:边/顶点磁吸 + 家具吸附 + 对齐虚线。
- **S4 墙内柜 + 尺寸标注 + 底图标定 + 面积 + 定位模式 + 手绘风视觉**:家具跨房间边界;边长常显开关 + 数值输入;按楼层标定(校正默认 scale);面积显示;搜索命中结果列表(角落,跨房子/楼层分组)+ 物品「定位」跳转高亮;移动端只读户型图 + 列表 CRUD。
- **S5 打磨**:撤销、重叠提示、乐观锁、小地图、移动端 pinch、空状态引导、网格吸附、复制房间。
