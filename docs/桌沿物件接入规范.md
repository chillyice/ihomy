# 桌沿物件接入规范

桌沿物件是桌面和平板页面两侧可点击的生活用品。设计一件新物品时，先确定它为什么会出现、点开能做什么，以及它在桌面上有多大、多高。已有的茶杯通往天气页，便签则对应一条仍有效的待办。两者共用摆放和投影机制。

## 画风与素材

- 沿用「旧画册水粉」。从正上方看物件，保持自然的尺度与正放朝向。用哑光色块交代材质，用少量断续的干笔、纸纹或釉面斑点表现使用痕迹。以现有水粉茶杯校对视角和笔触，缩到 80–120 px 时轮廓仍应清楚。[画风样张与出图提示词](设计想法/主题/暖居主题/旧画册水粉材质/窗下桌面与出图提示词.md)
- 单物件居中，背景透明，四周留出旋转所需空间。插画只画物件本身的明暗，桌面上的接触暗部、方向性长影与光照深度交给渲染层。蒸汽等装饰与主体分层，提示文字走中英文界面文案。
- 内置图以透明 WebP 放入 `frontend/src/assets/windowdesk/`，同名高清图放在 `hd/`，两档保持相同画幅、透明边距和定位。渲染器现有普通规格是 268 / 804 px，叶片是 168 / 504 px。新画幅按实际最大显示边长和项目资源预算选取，改变文件尺寸时同步 `illustrationSource` 的 `srcset` 宽度声明。
- 窄边会裁切物件。每个新插画或换形变体都要量一次正放、旋转 30° 时可见颜料的水平半宽，按完整画幅边长百分比登记到 `WindowDesk.vue` 的 `paintHalfWidths`。这两个数用于桌沿取景。投影轮廓另外读取页面实际加载图像的透明通道，照片则使用相纸外缘。悬停提示和独立动效不计入实体轮廓。

便签有原款、方格夹纸、鼠尾草绿贴纸三种外观，共用 `note` 的尺寸 0.75 和高度 0.01，点击打开对应待办。日记本有原款、亚麻蓝脊、陶土花纹三种封面，共用 `journal` 的尺寸 1 和高度 0.045，默认打开日记书架。首次加载和重新摆桌时抽取外观，数据刷新沿用当前款式。

## 尺寸与投影

| 登记项 | 取值方法 |
|---|---|
| `kind` | 业务种类的稳定键。例如 `cup` 包含 `coffee` 和 `tea` 两种插画，共用一种摆放尺度和有效高度。 |
| `sizeRatio` | 正方形插画相对桌沿基准画幅的边长比例，决定物件摆多大。 |
| `heightRatio` | 物件离桌面的有效高度除以完整正方形画幅所代表的边长。两者用相同单位测量，写入无量纲比例。卷起的书签按翘起高度估计，杯子按杯口到桌面的高度估计。 |

在 `frontend/src/utils/deskObjectProfiles.js` 的 `DESK_OBJECT_PROFILES` 中按 `kind` 登记这两个比例。以一个假想的薄盒为例，若完整画幅代表 20 cm，盒高 1 cm，则 `heightRatio = 0.05`。当画幅边长为 200 CSS px 时，其有效高度为 10 px。这个参数决定影长。要让薄盒的影子更贴桌，就核对盒高和画幅的比例。

方位角和高度角来自当前显示的窗光。设有效高度为 *H*，太阳高度角为 *α*，方位角为 *A*。屏幕坐标向右、向下为正，影长为 *H / tan(α)*，位移为 `(影长 × sin(180° − A), 影长 × cos(180° − A))`。正南光让影子向页面下方延伸，东南光使影子向右下，西南光使影子向左下。物件在桌面上旋转时，轮廓跟着旋转，光线方向始终由太阳决定。

两种窗影标准共用同一套物件投影。`deskShadowGeometry.js` 根据当前显示的太阳位置给出位移。`deskShadowMask.js` 取裁切、旋转后的实际轮廓，在已有的窗格与树影透光遮罩内沿位移方向绘制，并扣除物件自身正面。完全遮光处与同处的实心窗棂共用全局影色和深度，交叠处只遮一次，半影边缘自然较浅。制作新物件时只提供轮廓与高度，颜色与透明度统一由窗光层合成。

## 功能与交互

1. 在 `frontend/src/utils/deskObjects.js` 登记物件。可自选入口的常驻物件在 `DESK_DEFAULT_PATHS` 指定默认站内去向，允许绑定的页面来自 `DESK_DESTINATIONS`。与内容绑定的物件在 `buildDeskObjects` 根据可见数据构造稳定的 `key`、`kind`、`art` 或 `src`、`to` 及翻译键。便签应落到具体待办，通知信封应在有未读时才出现。
2. 复用 `deskPathAllowed` 和已有数据权限。确认入口已启用、当前显示模式可访问，账号或家庭切换后更新候选。用户自选入口失效时回到可访问的默认入口。两者都不可访问时跳过。物件名称和操作说明补齐中英翻译，已有业务权限继续由目标页面与服务端落实。
3. 摆放交给 `useDeskSpace` 和 `deskSpace.js`，由它们处理正文、卡片、侧栏和浮动按钮的避让，保持同次浏览中的摆放稳定。宽桌面可以完整展示，窄桌沿可只露一角，缺少可用空间时让出位置。沿用 `WindowDesk.vue` 的键盘焦点、点击区域和提示。模态打开时让后台物件退出交互，插画装饰不额外占用 Tab 顺序。
4. **手动拖动只在当前页面生效（V14.96/V14.97）**：指针按下后物件与投影一起跟随，松手把原处让给下方控件并保持就位；坐标不写存储，切换页面、刷新或重新摆桌即恢复自动摆放（旧版本保存过的拖动坐标直接丢弃，不做迁移）。滚动正文、控件进入视口、手机地址栏收起时保留可见物件坐标。窄边裁切的物件可上下移动或换边。续做记录在手机与平板由桌沿书签承接，不再另设首页/浮卡入口。
5. **外观换款与候选刷新（V14.87/V14.86）**：便签与日记本各三款插画，首次摆放与重新摆桌时抽取，数据刷新、拖动、筛选和打开日记再返回都沿用当前款式（取款口径在 `utils/warmMaterials.js`）；场景轮换（每小时、跨午夜、后台满 20 分钟返回）同时更新摆放与候选，恶劣天气照常关窗。

## 验收

| 场景 | 检查结果 |
|---|---|
| 素材与交互 | 普通屏和高像素密度屏上轮廓清楚。宽桌面、窄桌沿和 ±30° 倾斜时，露出的主体仍能识别和点击。键盘可打开同一目标。悬停提示、弹窗与减少动态效果均沿用现有行为。 |
| 数据与权限 | 常驻款可切换到允许的目标。业务款在状态有效时出现，状态失效或切换家庭后消失。禁用目标模块或使用儿童模式时只展示可达入口。 |
| 长度与方向 | 对同一有效高度，45° 高度角时影长等于物高，30° 时约为物高的 1.73 倍。上午与傍晚的横向分量互换方向。切换太阳时隙或窗影标准时，物件影与窗影一同移动。 |
| 深度与遮挡 | 提高、降低、归零全局阴影深度，观察窗格与物件。晴天完整受光、跨窗棂以及无直射光三种情况下，投影强弱随窗光，重叠处不出现二次加深。 |

修改候选或路由时核对 `deskObjects.spec.js` 和 `useDeskObjects.spec.js`。修改尺寸或裁切时核对 `deskSpace.spec.js`。改投影时核对物件与窗面投影测试。日常在仓库根执行 `node scripts/related-tests.mjs --run`，再用真实素材在页面上复核至少一个正南、一个斜照场景。
