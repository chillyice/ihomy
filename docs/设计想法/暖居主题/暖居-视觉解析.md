# 暖居主题 · 视觉解析稿(视觉模型 → 非视觉模型)

> **用途**:本文件是视觉模型对 `preview-dawn.png` / `preview-dusk.png` / `暖居-晨暮预览.html` 的**逐像素还原文字版**,供非视觉模型**不看图也能完整施工**。
> **配套**:架构与决策见同目录 `主题系统设计.md`;设计灵魂见同目录 `设计理念.md`。本文件只负责"图里长什么样"。
> **施工者须知**:本主题的**页面框架与「光尘」不同是允许且预期的**(见 §3、§4),不要为了兼容旧布局而缩手。两套主题共存,主体切换,旧页面结构该改就改。

## 0. 一句话气质

暖木 + 陶土 + 鼠尾草绿 + 奶油,像**午后客厅**:墙是暖米色背景,卡片是屋子里的**实木/羊皮家具块**(不是玻璃),右上角一扇**会呼吸的窗**——光柱斜照,浮尘缓缓蛇形漂移;入暮灯亮,整体转深咖与琥珀,近烛光。全程**慢、柔、克制、留白**。

## 1. 两轴心智模型(必须实现)

| 轴 | 取值 | 谁控制 |
|----|------|--------|
| **主题 theme** | `warm`(暖居,本主题·暖木旗舰)/ `guangchen`(光尘,现有配色保留) | 用户**手动**选 |
| **晨暮 mode** | `dawn`(晨/浅色)/ `dusk`(暮/深色) | 日出日落**自动**(可手动覆盖);`autoMode` 只切 mode,**不切 theme** |

- 原「明暗模式」= 现在的 **mode**;light→晨 `dawn`,dark→暮 `dusk`。
- **每个 theme 都必须各有 dawn 与 dusk 两套完整 token**(矩阵,不是"一套主题 + 全局明暗")。
- 应用方式:`html.theme-{id}` + `html.dark`(dusk 时挂 `.dark`,让 Element Plus 暗色 css-vars 继续生效)。
- 持久化 key 沿用 `ihomy-theme`;旧 `{dark,autoMode}` 迁移:`dark:false→mode:'dawn'`、`dark:true→mode:'dusk'`、`theme` 缺省 `'warm'`。

### 2.3 ⚠ 关键对比度规则(图里已体现,必须照做)

- **主色上的文字一律用 `var(--card)`**:晨是奶油字压深木,暮是**深咖字压琥珀**——图中暮色激活导航「首页」/「加粗主按钮」文字都是**深色**,与晨相反。写死白色字会导致暮色下看不清。
- 次要/幽灵按钮文字用 `--text-2`,底色 `--line`,hover 抬到 `--card-2`。
- 强调陶土按钮文字用 `#FFF7F0`(两档通用的暖白)。
- 绿标(`.tag.grn`)文字用 `var(--card)`。

## 4. 材质与光影规则(主题的灵魂,别退回玻璃)

- **卡片 = 家具块,不是玻璃**:`background:var(--card)` + `1px solid var(--border)` + `border-radius:16px` + `box-shadow:var(--shadow)`,padding:18px。**不要 `backdrop-filter` 玻璃拟态**——图中明确"卡片不再用玻璃,改为暖木/羊皮家具块"。
- 卡片 hover:仅 `box-shadow` 过渡到 `--shadow-hover`(0.35s)。暖居可再加"温光浮起"(§6.3),但**克制**,不要大缩放。
- 圆角:外壳 22px、卡片 16px、按钮/药丸/标签/导航 11px、小标签 9px、图标块 8px。
- 分隔线一律 `--line`,极淡。
- 背景氛围(`.atmos`, `position:fixed; inset:0; pointer-events:none; z-index:0`):
  1. `.sky` 两层暖色 radial-gradient(右上 `--bg-2`、左下 `--bg-2`,transparent 55~62%)叠 `--bg`。
  2. `.win` 一扇"窗"的框影:右上角 300×520,上下横梁 14px + 竖中梃 14px + 横中梃 14px,`rgba(120,88,50,.16)`(暮色 `rgba(255,206,150,.10)`)。这是暖居的**视觉签名**。
  3. `.beam` 斜光柱:340×760,`linearGradient` 暖白(#FFE9C4 .38 → #FFDDA6 .13 → 0),`mix-blend-mode:screen`,`filter:blur(2px)`,动画 `beamDrift` 14s 交替(rotate 4deg→9deg,translateX 0→-26px)。暮色 opacity 降到 .5。
  4. `.bloom` 暖光晕:220px 圆,`--glow-warm` radial,blur(30px)。
  5. `.dust` 浮尘 4~5 颗(§6.1)。

## 9. 施工前自检(来自 `设计理念.md` §五)

动手任何页面/组件前先问:**这符合"会呼吸的家"吗?是像摆家具还是像铺元素?**
取舍优先级:① 会呼吸(克制/留白/柔和/慢)→ ② 温度(暖色/中古/绿植)→ ③ 活人感(生活痕迹、不模板)→ ④ 满而不乱(主次/秩序/呼吸缝)。
