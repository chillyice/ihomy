# 设计理念 — 会呼吸的家(Design North Star)

> 本文是 ihomy 的**设计灵魂文档**(North Star),记录用户的情感与审美方向,作为**所有未来设计的分析基石**。用户每次表达的感受逐次累积于此;任何页面/组件/主题的取舍,都应回到本文校准。
> 状态:2026-09-09 首记,持续生长。

## 一、这个网站应该让人感到什么(用户原话)

> 我想要的这个网站是一个**会呼吸的、柔和安静**的,像是在**家里的沙发上坐着**,看着**清风吹拂纱窗飘动**,看着**光线透过窗户打在地板、桌面上**,空气中的**灰尘也隐隐漂浮**,打开**唱片机**享受着此刻的宁静,也有**绿植点缀**着房间,**中古风的房间设计**下,绿色也为家里添加了点不同的元素。

## 二、核心意境(可复用的意象库)

| 意象 | 语义 | 设计落点 |
|------|------|---------|
| 会呼吸 / 柔和安静 | 不吵、不急、有节奏地"活"着 | 动效克制动、留白、低对比柔和光感;避免高频刺眼动画 |
| 沙发 + 纱窗 + 风 | 身体的松弛感、家和庇护 | 主背景要有一层"光/风/浮尘"的慢速氛围层(而非纯色) |
| 光线打在地板/桌面 | 时间感、温度、光影变化 | 光的方向/色温随时刻变化(晨昏冷暖) |
| 灰尘漂浮 | 空气的实感、空间深度 | 细颗粒浮尘微粒动画、景深、层次感 |
| 唱片机 | 慢生活、仪式感、驻留 | 克制的叙事性装饰、背景音乐入口、静谧的"驻留感" |
| 绿植 + 中古风 | 生机 + 复古温度、满而不乱 | 暖木/陶土色 + 点缀绿;复古材质与暖光 |
| 活人感 / 令人感动 | 不冰冷、有生活痕迹、有"人住过"的痕迹 | 细节有温度、数据有生活感、不模板化 |

## 三、设计方法论(用户提炼)

> 设计网站样式就好像**设计装修**一样:**家具的位置摆放、颜色配合、满又不乱**,有一种**活人感**,令人感动。

- **把组件当作"家具"**:每块卡片是房间里的家具——位置、大小、材质、与邻里关系都按"摆家具"来设计,而不是"铺元素"。
- **满而不乱**:内容可以丰富,但必须有主次、有秩序、有呼吸缝;宁可留白,不填得过密。
- **颜色配合而非堆砌**:一套协调的暖色调(木头/陶土/奶油/浅绿)贯穿,像装修配色,不是零散的高亮色。
- **活人感**:有生活痕迹(动态、时间、家人、温度),不是产品说明书式的冰冷仪表盘。

## 四、落地偏好(用户明确表达)

1. **天气组件是被认可的桥**:用户「有点喜欢这个天气组件了」,认为**配合 AI 生图**能构造"一块真实生动、可以让人实时感受变化的空间"。
   - 方向:天气不应只是一张卡,而是一个"窗"——AI 生成的城市氛围场景,随天气/晨昏/季节实时变化,让人感受到外界在呼吸。
   - 这是"光线/风/季节"意象的最佳载体,应作为主题系统里体现"真实感与时间感"的核心触点。

2. **主题系统**:
   - 「增设主题切换功能」——不再只有一套明暗,而是**多套主题**。
   - 「原来的深浅模式也改下名字」——现行 `明暗模式`(light/dark)改名。
   - 「每个主题都做深浅模式」——**主题 × 深浅(EACH theme has its own light & dark variant)**的矩阵,而不是"一套主题 + 全局深浅"。

## 五、给未来会话的分析提示(怎么用本文)

- 读本文后再动手做任何 UI/主题/动效,先自问:"这符合'会呼吸的家'吗?是像摆家具还是像铺元素?"
- 设计取舍按优先级:① 会呼吸(克制、留白、柔和、慢) → ② 温度(暖色、中古、绿植) → ③ 活人感(生活痕迹、不模板) → ④ 满而不乱(主次、秩序、呼吸缝)。
- 用户偏好"看具体渲染再定",而非抽象描述——做设计时优先给可看的渲染/预览,再收敛。
- 每当用户再表达感受,继续追加到本文,保持它是"北星"。

## 六、主题系统锁定决策(2026-09-09,用户拍板)

> 主题系统实现了「会呼吸的家」的载体层,锁定以下框架,实施细节见 `docs/主题系统设计.md`。

1. **主题 = 装修风格**(手动选,决定全局主色/材质);**晨/暮 = 时间光照档**(沿用日出日落自动切晨暮,也可手动)。自动模式**只切晨暮、不切主题**——这是两轴矩阵,不是"一套主题 + 全局明暗"。
2. **原来的"明暗模式"改名**:light→「晨」、dark→「暮」(zh-CN `theme.light/dark` 改 `theme.dawn/dusk`)。
3. **每个主题都做晨/暮两档**:主题 × 晨暮 的矩阵。
4. **主题池只做两套**:现有这套(奶油暖底+玻璃磨砂+主色 `#b88c6e`)定名 **「暖居」(Warm Dwelling)**;全新旗舰 **「光尘」(Light & Dust)**(暖木+陶土+鼠尾草绿+奶油,签名=一扇会呼吸的窗)。旧的 `theme.presets`(旧物之家/海蓝/森林等)是旧方案名,废弃不用。
5. **「光尘」的天气→AI生图**放大为**全局全屏氛围背景**(光尘默认开启):把天气做成"一扇活窗",随晨昏/天气/季节实时变化,让外界在呼吸。生图优先绑 seedream-5.0-pro(真实感与时间感的核心触点)。
