## 1. 目标页面结构

```
┌───────────────────────────────────────────────┐
│ hero: 现在（城市/温度/9 指标） │ 预警（右起排列） │
└───────────────────────────────────────────────┘
  [分钟降水一句话 · 并入逐小时卡顶部]
  逐小时（24h/72h × 折线/卡片）
  ── 未来 ──
  10 天预报（前 3 天细列 + 后 7 天精简列）
  ── 空气与天空 ──
  空气质量（AQI 主指标 + 折叠明细）
  日月与晨昏（世界地图 + 晨昏线 + 点击地点 → 信息面板）
  生活指数（紧凑网格，点击看全文）
```

- 区块顺序:实况(含预警) → 逐小时(含分钟降水) → 10 天 → 空气 → 晨昏地图 → 生活指数。
- 视觉权重三级:**L1 hero** / **L2 逐小时、10 天** / **L3 空气、晨昏、生活指数**（安静块）。
- 目标:默认页面高度从 2706px 降到 **≤ 1900px**；首屏（720px）能看到「现在 + 未来两小时」；完整信息通过展开/弹窗仍可获取。

## 2. 设计决策（已定，不要推翻）

1. **预警右置、右起排列**:桌面端预警列在实况右侧，最多占 hero 顶部行宽的 46%；多个预警按严重程度降序，**最严重的排最右**，其余向左延伸，溢出时横向滚动且初始停在最右。窄屏（≤900px）预警整行落到实况下方，按正常从左到右阅读。
2. **预警默认紧凑**:显示等级色左边条 + 标题（类型+级别）+ 起止时间 + 正文 2–3 行截断；点击整卡打开详情弹窗看完整正文与防御指南。弹窗必须 `append-to-body` + 限宽（见 `docs/UI设计提示词.md` §18a）。
3. **晨昏地图的数据来源单一**:太阳直射点与当前太阳高度**由后端 `SolarUtil` 计算**并随 `sun-info` 返回；前端只做几何渲染（逐像素高度角由直射点推），**禁止把 NOAA/Meeus 算法再移植一份到前端**（与「同一事实只留一份来源」一致）。
4. **地图用 Canvas，不用地图库/瓦片**:等距圆柱投影，世界轮廓用 Natural Earth 110m 公共领域数据一次性生成 SVG path（构建时资产，无运行时依赖）。夜/晨昏用半透明色带叠加，边界即晨昏线。
5. **近细远粗**:逐小时默认 24h 折线；10 天预报前 3 天保留全部列，后 7 天只留日期/天气/温度条；生活指数全部保留但压成紧凑网格 + 点开看全文；空气质量默认只留主指标，明细折叠。
6. **颜色收敛**:强调色每屏只服务一件事（预警用级别色、AQI 用等级色、温度渐变只留在图表）；其余文字走 `--color-text-secondary`。
7. **不删除任何现有数据能力**:9 个晨昏时刻、月相、5 天月相条、污染物、健康建议、24h AQI 走势、3 天 AQI 仍然全部可达，只是改变默认可见层级。

### B1. 后端:补太阳直射点与当前太阳位置（不新增接口）

**新增 SolarUtil 公共方法**:

```java
/** 太阳直射点(纬度=赤纬,经度由 UTC 时刻与均时差反解),返回 {lat, lng}。 */
public static Map<String, Double> subsolarPoint(Instant instant)

/** 指定地点/时刻的太阳高度角与方位角(度),返回 {altitude, azimuth}。 */
public static Map<String, Double> sunPosition(double lat, double lng, Instant instant)
```

实现要点:
- 复用现有私有 `julianDay/julianCentury/sunDeclination/eqOfTime/sunAltAz`。
- 直射点经度:`lng = (720 - utcMinutes - eqOfTime) / 4`，归一化到 `[-180,180]`；纬度 = `sunDeclination`。
- 方位角沿用 `sunAltAz` 的约定（正北 0°、顺时针）。
- 结果保留 1 位小数（与 `subsolar` 精度足够画图）。

**SunService#getSunInfo** 追加（放在 `data.put("date", ...)` 之后）:

```java
data.put("generatedAt", Instant.now().toString());
data.put("subsolar", SolarUtil.subsolarPoint(Instant.now()));
data.put("current", SolarUtil.sunPosition(lat, lng, Instant.now()));
```

- 不写 Redis（变化快、计算量极小）；`slots` 的现有缓存逻辑不动。
- 响应增量 < 200 字节；前端旧版本忽略新字段，向后兼容。

**测试**（加到 `SolarUtilTest`）:
- 春分/秋分 UTC 12:00 左右直射点纬度 `≈ 0`（±1°）、经度 `≈ 0`（±1°）。
- 夏至 UTC 12:00 直射点纬度 `≈ 23.4`（±1°）。
- `sunPosition` 在直射点处高度角 `≈ 90`；对跖点 `≈ -90`；北京正午高度角落在 `(0,90)`。
- 保持 `mvnw -B test` 全绿（测试数 56 → 59 左右）。

```js
  astro: { type: Object, default: null },       // 9 个时刻 + 月相
  slots: { type: Array, default: () => [] },    // 288 点,画今日高度曲线
})
```

**布局**:

```html
<div class="wt-map-card">
  <div class="wt-map-wrap">
    <canvas ref="canvasEl" aria-hidden="true"></canvas>
    <button class="wt-map-marker" :style="markerStyle" :aria-label="$t('weatherPage.map.hint')" @click="focusPanel">
      <span class="wt-map-ring"></span>
    </button>
  </div>
  <div class="wt-map-panel" :class="{ focused }"> ...阶段/高度/方位/下一阶段/9 个时刻/月亮/今日高度曲线... </div>
</div>
```

- 桌面:`grid-template-columns: minmax(0, 640px) 1fr; gap: 18px`；地图宽 100%、`max-width: 640px`、`aspect-ratio: 720 / 288`。
- 手机（≤900px）:单列，地图在上、面板在下；点击地点后 `scrollIntoView({ block: 'nearest', behavior: 'smooth' })`。

**Canvas 绘制**:

1. 逻辑尺寸 720×288，按 `devicePixelRatio` 放大 backing store；`ctx.setTransform(dpr,0,0,dpr,0,0)`。
2. 计算逐像素太阳高度:预计算行 `sinLat/cosLat`、列 `cosH`（`H = lng - subsolarLng`），`alt = asin(...)`；720×288 ≈ 207k 点，一次性 `ImageData` 填充。
3. 色带（按主题两套，读 `document.documentElement.classList.contains('theme-warm')`）:
   - 白天:透明
   - 民用:`warm rgba(120,105,85,.10)` / `guangchen rgba(90,110,150,.10)`
   - 航海:`warm rgba(100,90,75,.20)` / `guangchen rgba(65,85,130,.20)`
   - 天文:`warm rgba(80,72,62,.32)` / `guangchen rgba(40,55,100,.32)`
   - 夜间:`warm rgba(60,54,48,.48)` / `guangchen rgba(20,30,60,.50)`
4. 绘制顺序:陆地填充 → 晨昏色带 → 陆地描边（细、低对比）→ 30° 经纬网 → 赤道/本初子午线 → 城市点。
5. 陆地路径用 `Path2D(WORLD_LAND_PATH)`；颜色从 `getComputedStyle(document.documentElement)` 读 `--color-card-2` / `--color-text-tertiary` / `--color-border`，主题切换时重绘。
6. 城市点由 Canvas 画小圆 + HTML `.wt-map-marker` 按钮叠在百分比位置（`left:(lng+180)/360*100%`、`top:(84-lat)/144*100%`），按钮是唯一点击目标，保证键盘可达。
7. 重绘触发:mount、容器尺寸变化（ResizeObserver）、主题变化（watch `themeStore.theme/mode`）、每 60s 定时器（`driftSubsolar` 推进经度）；`document.hidden` 时暂停、可见时恢复。**不要用 rAF 常驻循环**。
8. 性能:单次重绘目标 < 20ms；复用 `ImageData` 缓冲，不在每帧分配。

**面板内容**:

- 阶段徽标:由 `current.altitude` 经 `twilightStage()` 得出，颜色:白天琥珀、民用橙、航海蓝、天文深蓝、夜间灰。
- 太阳高度 / 方位:`current.altitude`、`current.azimuth`（保留 1 位小数）。
- 下一阶段:`nextTwilightEvent(astro, nowMinutes)` → 显示「日落 17:48（1 小时 23 分后）」；无事件显示 `—`。
- 9 个时刻:3×3 网格（天文/航海/民用晨光始、日出/正午/日落、民用/航海/天文昏影终），空串隐藏。
- 月亮:沿用现有 `moonIcon/moonPhaseName/moonDays`（月相、照明、月出月落、5 天月相条）。
- 今日太阳高度曲线（可选但推荐）:用 `slots` 画 720×90 的 SVG，横向 0–24 时，背景画 `0/-6/-12/-18` 四条阈值线与色带，竖线标「现在」；这是地图之外的第二个「晨昏曲线」，成本低、可读性高。

**降级**:
- `subsolar` 缺失（旧后端/接口失败）→ 不渲染地图，只渲染 9 个时刻 + 月亮（即当前静态卡的能力）。
- Canvas 异常 → `try/catch` 后同样降级，不影响页面其它区块。

### B5. 接入 `Weather.vue`

- 用 `<TerminatorMap>` 替换现有「日月与晨昏」卡；保留 `astro` 的取数逻辑（共享优先、日期不符自取）。
- 传给组件的 `slots` 取自 `astro.value?.slots`（共享的 `sunInfo` 自带）。
- 若 `astro.subsolar` 不存在但 `astro.date` 是今天:在 `load()` 里补一次 `publicApi.getSunInfo()`（这是新字段上线初期的兼容路径）。
- 删除旧 `.wt-twilight` 的 9 个时刻行与 `.wt-moon` 模板块（能力迁到面板），避免重复展示。
- 保留 `.card` 的 L3 安静样式。

### B6. 无障碍与规范

- Canvas `aria-hidden="true"`；信息由面板文本承载。
- 地图按钮 `aria-label` 说明「查看此地此刻的晨昏」，Enter/Space 可触发（用 `v-a11y-click` 或原生 `<button>`，推荐原生 button）。
- 所有用户可见文案走 i18n；不得出现裸中文。
- 不使用 `v-html`；地图不涉及 HTML 注入。
- 组件拆分后 `Weather.vue` 目标 ≤ 1100 行（新组件独立）。

## 6. 风险与已知坑

1. **预警列与 9 指标网格争宽**:hero 顶部行右侧预警最多 46%，指标网格仍在下方通栏；不要让预警挤压指标。若 1280 下实况文字换行，把预警上限降到 40%。
2. **row-reverse 横向滚动**:不同浏览器初始滚动位置不一致，必须实测并显式设置 `scrollLeft`。
3. **Canvas 与 CSS 变量**:Canvas 不能直接使用 `var(--x)`，每次主题切换要重新读 `getComputedStyle` 并重绘；不要在模块加载时只读一次。
4. **地图数据漂移**:用后端 `generatedAt` 计算已过分钟数再推进直射点经度；没有 `generatedAt` 时按「当前时刻」处理（误差最多几小时 = 几十度经度，务必在有该字段后再上线地图）。
5. **极昼极夜**:`astroTimes` 会返回空串；`nextTwilightEvent` 必须容忍空值，不能算出 `NaN` 或显示 `Invalid Date`。
6. **两套主题色值**:暖居/光尘的色带要分别实测；深色下夜间色带不要与卡片底色糊成一片（可加 1px 边界或提高 alpha）。
7. **Element Plus 表格拆表**:两张表各自 `stripe`/`size` 一致，避免视觉上像两个不同组件。
8. **懒加载与入口 chunk**:`world-land-path.js` 只能被 `TerminatorMap.vue` 引用；不要放进 `utils/` 被主包间接引用。
9. **i18n 守门**:新增键必须中英同步，且所有模板文本走 `$t`；`{`/`}`/`@` 转义。
10. **后端缓存**:`sun-info` 只缓存 `slots`，新字段每次请求实时计算；不要误把整个响应缓存成 12 小时，否则晨昏线会停在旧位置。
