## 1. 第二批:正则测试 + 文本清洗与对比 + 四个现有页扩展

> 全部纯前端、零新依赖。预计两个新页面 + 四处就地扩展。

### 1.1 正则测试(`/tools/regex`,kernel `regexTool`)

- 能力:pattern + flags;实时高亮匹配、捕获组/命名组表格(含组名/index);替换预览(`replace` 与函数语义说明)、split;常用正则库(邮箱/URL/IPv4/手机号/身份证/日期/中文),一键填入。
- 安全:**ReDoS 防护必须做**——匹配跑在 Worker 里,超时(建议 1s)即中断并提示;同一表达式不自动重试。渲染上限:匹配列表超阈值截断提示。
- 边界:非法正则给出可读错误(含错误位置,`new RegExp` 的 message 直接透传不合适,需映射);`g` 标志下 `lastIndex` 不跨次执行残留(每次 fresh RegExp)。
- 验收:中文/emoji/多行输入正确;`/tools/regex` 与 chunk 200;bit_pouch 侧无对应插件(`new`)。

### 1.2 文本清洗与对比(`/tools/text`,kernel `textTool`)

- 合并进一页的四个模式(页内切换):
  1. **清洗**:去重/排序/反转/去空行/trim/加前后缀/行编号/join-split;全半角转换;字数统计(字符/中文字/词/行/字节)。
  2. **命名转换**:camelCase / snake_case / kebab-case / PascalCase / CONSTANT_CASE,一次输入多路输出(与编码页「一进多出」同构)。
  3. **Markdown 表格**:CSV/TSV/竖线分隔 → Markdown 表格(对齐可配),反向也可(表格 → CSV)。
  4. **文本 diff**:行级 Myers diff,忽略空白/大小写开关;左右双栏视图,超长(建议 >2000 行)截断提示;不引依赖,手写 Myers(带单测:相同/新增/删除/乱序)。
- 验收:各模式空输入给空态不报错;diff 对中文与 CRLF/LF 混合输入稳定(统一按 `\n` 归一后比较,原文展示不改动)。

### 1.3 四个现有页扩展(不新开卡片,就地加 tab/模式)

| 页面 | 扩展 | 要点 |
|---|---|---|

## 2. 第三批:运维命令速查 + 图片与文件

### 2.1 运维命令速查(`/tools/ops`,内容型,无 kernel 算法)

- 定位:可搜索、可分类、可复制的命令手册,数据为静态 TS/JS 常量(不接后端);游客可用。
- 命令域:systemd/journalctl、docker/compose、nginx、ssh/scp/rsync、tar/zip、grep/find/sed/awk、df/du/ps/top、mysql/redis-cli、curl/ss/dig、certbot、ufw/iptables、git 常用;每条含说明、占位符(如 `{service}`)与复制。
- **危险命令标记**:`rm -rf`、`dd`、`mkfs`、`systemctl disable`、`iptables -F`、`DROP TABLE` 等必须带显眼标记;复制危险命令时前端二次确认(ElMessageBox)。
- 附参考表:HTTP 状态码、常用端口、MIME 类型、nginx 配置片段(与 ihomy 部署实际一致的 gzip/缓存/反代写法)。
- 工作量在**整理命令库**:先定 schema(`{id, domain, title{zh,en}, command, note{zh,en}, dangerous?, refs?}`),分文件按域维护,便于后续并入 bit_pouch。
- 验收:搜索按标题/命令/说明命中;移动端不溢出;危险命令确认不可绕过。

### 2.2 图片与文件(`/tools/image`,kernel `imageTool` + `fileTool`)

- 图片:压缩/缩放(canvas + `toBlob`,格式 WebP/JPEG/PNG 可选、质量可调)、favicon ICO 多尺寸生成(16/32/48/64/128/256,手写 ICO 打包器)、图片→Base64/Data URI、EXIF 查看(手写 JPEG APP1 解析)与清除(重编码即剥离)。
- 文件:类型识别(magic bytes 常见 30 种)、文件哈希(复用第一批 `hashTool` 的 `runFile`,跨工具复用不复制)、ZIP 打包/解压(`fflate`,需登记,独立 chunk)。
- 隐私:全本地处理;大图(>30MB)提示性能风险;输出文件不落存储。
- 验收:各能力带单测的部分(ICO 打包、EXIF 解析、magic 识别、ZIP 名称冲突策略)先测;视觉类(压缩画质)人工冒烟。

## 3. 第四批:JWT 与密钥 + 颜色设计 + 单位换算;网络诊断单列

### 3.1 JWT 与密钥(`/tools/jwt`,kernel `jwtTool`)

- JWT 解码:header/payload、exp/nbf/iat 可读化与过期判定;HS256/384/512 验签(WebCrypto);RS/ES 验签(导入 SPKI PEM/JWK)。
- 密钥:RSA/ECDSA 密钥对生成(`crypto.subtle.generateKey`)、PEM↔JWK 互转、公钥指纹;AES-GCM 文本加解密(PBKDF2 派生)。
- 安全口径:全程本地;**令牌/密钥/明文一律不落任何存储**;输入框不回显历史;页面明确提示「内容不会上传」。
- 注意:ihomy 已有 `utils/jwt.js`(仅解析 exp,用于令牌预检)——新 kernel 独立建文件,不混用;避免与登录态逻辑耦合。

### 3.2 颜色与前端设计(`/tools/color`,kernel `colorTool`)

- HEX/RGB/HSL/HSV/LAB 互转(手写,带单测)、WCAG 对比度(AA/AAA 判定)、互补/邻近/三分配色、CSS 渐变/阴影/圆角生成与 cubic-bezier 编辑。
- 与光影实验台(`/tools/light-lab`)无关,不合并;产出可复制 CSS 变量片段。

### 3.3 单位换算(`/tools/unit`,kernel `unitTool`)

- 长度/面积/体积/重量/温度/速度/压力/数据量/时间;换算系数静态表 + 单测;温度用偏移公式特殊处理。
- 与贷款计算器同属「生活计算」分类。

### 3.4 网络诊断(**暂缓,先过安全方案**)

- 形态:HTTP 探活(状态/耗时/响应头/重定向链/证书到期)、TCP 端口连通、DNS 记录(A/AAAA/CNAME/MX/TXT)、公网 IP。浏览器受 CORS/混合内容限制,**必须后端实现**,因此与其他批次不同、单独立项。
- **开工前置(安全方案,须先评审通过再写码)**:
  1. 仅登录用户可用(新增权限码进 `sys_auth`+`sys_role_auth` 种子,或至少 requiresAuth);
  2. 服务端出站限制:禁止云元数据/链路本地(`169.254.169.254` 等)/回环目标,端口白名单或上限,单次超时与目标数上限;
  3. 限流(用户级+全局)、不回显原始 banner、结果不缓存不落库;
  4. 写接口 `@OperationLog`;明确 SSRF 威胁模型与残余风险(内网探测面),拿到拍板后再实现;
  5. 不做任意 URL 抓取/代理。
- 方案通过后:后端 `NetProbeController/Service` + 前端 `/tools/net`;该工具在 bit_pouch 桌面端走系统网络栈,ihomy 侧即先发验证。

- bit_pouch 已有插件(hash/timestamp/uuid/regex/jwt/json/codec/base/packet/subnet)一律不直接覆盖,先比能力再合并。
