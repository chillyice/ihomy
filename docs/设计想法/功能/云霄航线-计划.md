# 云霄航线(Skyway 64)——环线跑道新棋局设计

> **状态**:设计稿,**未开工**(2026-11-17)。本文是规则与盘面的唯一定稿来源,开工前先读本文 + `frontend/src/utils/games/ludo.js`(现成内核范式)。
> **定位**:与现有飞行棋「航线 52」并列的**新棋局**(不是它的模式开关):同样是四架飞机、起飞格、航线、终点,但盘面改为**64 格环形主航线 + 四角机场 + 螺旋进近**,并新增**顺风 / 雷暴 / 备降机场 / 迫降 / 双分支高空急流**五类事件格。
> **复用**:纯函数内核分层、逐格 frames 动画、房主权威房间同步、`useGameView` 一屏适配,全部照抄 `ludo.js` / `Ludo.vue` 的既有做法;**不改动** `/games/ludo` 与 `public/runway-52.html`。

---

## 0. 一句话

四机长各守一座机场,沿 64 格环线飞满一圈后**盘旋下降进近**,途中被顺风推一把、被雷暴吹回来、在备降机场落地检修、在高空急流上抢先——**先让四架飞机全部停进停机坪的人赢**。

### 与原飞行棋的差异

| 维度 | 航线 52(现有) | 云霄航线(本设计) |
|---|---|---|
| 主航线 | 52 格,十字形交叉盘 | **64 格,闭合环形**(17×17 外周) |
| 归航跑道 | 直条 6 格 | **8 格弧形盘旋进近**(四角螺旋下沉) |
| 安全格 | 4 个起飞格 | **起飞坪 4 + 备降机场 4**(共 8,12.5%) |
| 事件格 | 无异色事件 | **顺风 +3 / 雷暴 −2 / 迫降 / 双分支急流** |
| 决策点 | 选哪架飞 | 选哪架飞 + **急流二选一**(飞得远 vs 能撞机) |
| 撞机收益 | 无 | **撞掉对手后再掷一次**(鼓励进攻) |
| 单架航程 | 55 步 | **72 步**(64 环 + 8 进近),提供短局 |

## 1. 盘面

### 1.1 结构

```
   主航线 64 格(环形,顺时针):★起飞坪 »顺风 ⚡雷暴 ◎备降机场 ⇢急流 ⚠迫降 ↳进近口

   ┌─ 起飞坪(左上角)+ 机场广场 ────────────────────────────┐
   │  ★══»──·──⚡──·──◎──⇢──·──·──⚠──·──·──·──↳  ┐         │
   │      (一段 16 格:cells 0..15)              │ 机库 2×2  │
   │                                            │  ↓        │
   │      8 格弧形盘旋进近  ──────────────────→  2×2 停机坪位 │
   └────────────────────────────────────────────────────────┘
         ↻ 另外三座机场广场:同一份图形 rotate 90/180/270 复用
         ⇢⇢ 急流虚弧:盘面内侧的虚线航路,可从机场广场上空跨过(画在广场之下)
```

- **主航线**:64 格闭合环,顺时针。`0/16/32/48` 四格是四家的**起飞坪**(盘面四角),`63/15/31/47` 是四家的**进近口**(起飞坪的顺时针前一格)。
- **机场广场**:四角各一座,含 **4 个机库停机位**(未起飞)、**8 格盘旋进近**、**4 个停机坪位**(终点)。四座广场旋转对称,只有配色和主城名不同。
- **进近段是私有的**:别的颜色进不来,所以进近段内不会撞机。
- **中央**:罗盘/气象雷达装饰区;四条高空急流虚弧在盘面内侧跨过(可从机场广场上空掠过——它是高空航道,画在广场之下,也不参与撞机)。

### 1.2 格子排布(每 16 格一段的固定模板,四段相同、只有配色不同)

以**自家起飞坪算第 1 格**,一段 16 格的顺序固定如下(四段完全一致 → 四家期望路径相同):

| 段内格位 | 类型 | 效果 | 盘面记号 |
|---|---|---|---|

| 2 | 普通航段 | — | · |

| 4 | **顺风航道**(奖励格) | 再前进 **3 格** | » |
| 5 | 普通航段 | — | · |
| 6 | **雷暴云**(惩罚格) | 后退 **2 格** | ⚡ |
| 7 | 普通航段 | — | · |
| 8 | **备降机场** | 安全格,不可被撞;也是迫降落点 | ◎ |
| 9 | **高空急流**(飞跃航线) | 二选一:急流 **+10**(不撞机)/ 低空 **+4**(可撞机) | ⇢ |
| 10 | 普通航段 | — | · |

### 1.3 几何(实现口径,与 mock 一致)

- 盘面 `viewBox="0 0 1000 1000"`,按 **17×17 网格**铺:四边外周正好 17×4−4 = **64 格**,格距 `920/17 ≈ 54.1`。
- 环序:`0` = 左上角,顺时针;`16k` 为各色起飞坪,`16k+15` 为该色进近口(即起飞坪顺时针前一格),两格相邻 → 进近从机场广场的外角起弧。
- 四角机场广场各占内圈 **6×6** 格(≈324px):外角起弧的 **8 格弧形进近**(贝塞尔插值定位),内角 **2×2 停机坪位**,另一侧 **2×2 机库位**;广场用一份 `<g>` 定义 + `rotate(90/180/270)` 复用,配色走 `currentColor`。
- 急流虚弧:从急流格圆心到落点格圆心的二次贝塞尔,控制点向盘心偏移,画在高空层的虚线;**绘制顺序在机场广场之下**,所以它可以从广场上空跨过而不影响读图。

## 2. 规则

### 2.1 步数模型

每架飞机一个整数 `step`:

| step | 含义 |
|---|---|
| `0` | 停在自家机库(未起飞) |
| `1..64` | 主航线第 1..64 格;第 64 格 = **自家进近口** |
| `65..72` | 自家盘旋进近 8 格;`72` = **停机坪位**(终点,必须正好落到) |

单架总航程 **72 步**。环上落点换算:`ringIndex = (start[color] + step - 1) % 64`,`start = [0,16,32,48]`。

### 2.2 掷骰与走子

1. 掷 1 颗骰子(1–6)。
2. **可走的飞机**:
   - `step = 0`:仅掷 **6** 可起飞 → 落到 `step 1`(起飞坪)。
   - `step 1..71` 且**未在检修**:`raw = step + d`;`raw > 72` 时**弹回** `to = 144 - raw`;否则 `to = raw`。
   - `step = 72`:已到家,不再动。
   - **检修中**(`repair > 0`)的飞机不能选。
3. 选一架走完 → 结算落点(§2.3) → 判撞机(§2.5) → 判是否连掷。
4. **连掷**:掷出 **6**、或**撞掉对手飞机**,同一玩家再掷一次;**每回合最多掷 3 次**(防止无限连锁)。
5. 无飞机可动 → 直接过手(记一条"无可调度"记录)。

### 2.3 落点结算顺序(唯一流水线,实现照此写)

```
落地 to
├─ to 在 65..72(进近段)          → 不结算任何格子效果
├─ to = 64(自家进近口)           → 不结算效果(下一回合自然进入 65)
└─ to 在 1..64(主航线)
   ├─ 起飞坪 / 备降机场           → 安全,无效果
   ├─ 顺风航道                    → to = min(to + 3, 64);不再触发任何格子效果
   ├─ 雷暴云                      → to = max(to - 2, 1);不再触发任何格子效果
   ├─ 机械故障                    → to = to - 4(同段备降机场);repair = 2
   └─ 高空急流                    → 由玩家二选一:
                                    ├─ 急流:to = min(to + 10, 64);**不撞机**
                                    └─ 低空:to = min(to + 4, 64);**正常撞机**
一次移动最多结算一次位移效果(顺风/雷暴的落点即使又是事件格也不再生效),避免连锁与死循环。
```

### 2.4 元素交互矩阵(实现与文案都以此为准)

| 从哪来 → 落到哪 | 是否再触发格子效果 | 撞机结算 | 备注 |
|---|---|---|---|
| 普通点数 | 是(触发落点那 1 次) | **是** | 唯一正常触发事件格的入口 |
| 顺风 +3 | 否 | **是** | 顺风把你推到对手身上,照样撞 |
| 雷暴 −2 | 否 | **否** | 被吹回不算主动撞击 |
| 迫降(→备降机场) | 否 | **否** | 备降机场是安全格,同格不撞 |
| 急流 +10 | 否 | **否** | 高空直飞,跨过谁都不撞 |
| 低空 +4 | 否 | **是** | 低空掠过,可吃前方 4 格上的对手 |
| 起飞(→起飞坪) | 否 | **否** | 起飞坪是安全格 |
| 弹回(超终点) | 否 | **否** | 弹回只落在进近段 |

### 2.5 撞机与安全格

- 落在**主航线**某格的最终位置后,若该格**不是安全格**,把**该格上所有其他颜色的飞机**全部送回各自机库(`step = 0`),撞机者**再掷一次**。
- 同色飞机可以叠在同一格(不互撞),显示为叠放 + 数字角标。
- **安全格** = 起飞坪 + 备降机场:格上的飞机不可被撞,任何颜色都可以停在上面叠放。
- 进近段是私有跑道,不存在撞机。

### 2.6 检修(迫降代价)

- 触发机械故障时:飞机退到本段备降机场格,`repair = 2`。
- **自家回合开始时**:所有自家 `repair > 0` 的飞机各减 1;`repair > 0` 的当回合不可选。
- 净效果:**这架飞机错过你下一次掷骰的回合**,机场格上安全、不被撞,其他飞机照常飞。
- 若四架全在检修,本回合掷骰后无子可动 → 过手。

### 2.7 胜负与记分

- 四架全部到 `step 72` 即胜;**必须正好落到 72,多出的点数弹回**。
- 房间局记分 = `已进坪架数`(0–4),与 `ROOM_RESULT_FIRST` 胜负口径一致(第一个满 4 架者胜)。
- 可选**短局**:先 **2 架**进坪即胜(约 12–18 分钟),标准局约 25–40 分钟。

## 3. 决策点与 AI

### 3.1 玩家的真实选择只有两个,但每个都有信息含量

1. **走哪一架**:起飞 / 抢进近 / 去撞人 / 躲安全格 —— 与原飞行棋同源。
2. **急流还是低空**:唯一的新增选择。`+10` 更快但跨过谁都撞不到;`+4` 走得少,但如果正好有对手停在前 4 格,就能顺手撞回机场并再掷一次。**"前面有人就低空,没人就急流"** 是玩家一局就能学会的策略。

### 3.2 AI 评分(照 `ludoAiPick` 的口径)

```
分数 = 撞机架数 × 120
     + 进坪 × 80
     + 起飞 × 26
     + 急流 × 30 / 低空撞机时按撞机计
     + 落点距离 × 0.4
     − 落在机械故障格 × 35
     − 落在雷暴格 × 18
     − 弹回 × 30
     + 落在备降机场(安全) × 8
     + 落在顺风航道 × 12
```

急流与低空作为**同一架飞机的两个候选 move** 一起进 `moves[]`,AI 只是打分更高者,UI 则高亮两条弧让人点。

## 4. 平衡与节奏

- **四段旋转对称 + 三类格各 12.5%**:任何座位、任何人数(2 人对角 / 3 人 / 4 人满场)期望路径一致,不存在位置优势。
- **航程 72 步 ≈ 原棋 55 步的 1.3 倍**,但顺风/急流净加速约 +6 格/圈,期望有效航程 ≈ 66 步/架;四架 + 撞机回送 + 迫降检修,标准局 25–40 分钟,提供短局兜底。
- **负面强度分级**:雷暴 −2(轻)→ 迫降 −4 且停 1 回合(重)→ 撞机回机库(最重)。负面总占比 12.5%,低于"正面 + 安全"合计 25%,体感是**加速为主、惩罚点缀**,不会变成互相拖后腿。
- **连掷上限 3 次**:撞机奖励再掷后仍有上界,单回合不会无限滚雪球。
- **迫降的定位**:不是"退格惩罚",而是"临时改降到最近的机场检修",叙事与机制一致,且落点是安全格(不会被追着打),家庭场景里小孩被罚后不至于崩盘。

## 5. 视觉与动效(口径给 UI 提示词用)

- **配色**:夜间航图——深海军蓝底 + 细经纬网 + 四家高亮描边色(珊瑚红 / 琥珀金 / 青碧 / 天蓝),格线极细,事件格用**低饱和底色 + 高对比记号**而不是彩色实心块(避免 64 格花屏)。
- **事件格记号**:★起飞坪、»顺风(三道风纹)、⚡雷暴(积雨云剪影)、◎备降机场(塔台光圈)、⇢急流(虚线弧 + 箭头)、⚠机械故障、↳进近口。
- **螺旋进近**:8 格沿弧线排布,进入时飞机逐格沿弧线滑行并**缩小/转向**,到家时停进 2×2 停机坪位。
- **动效**:顺风=车身加速残影;雷暴=屏闪 + 抖回 2 格;迫降=飞机绕半圈落到备降机场并挂"检修中"角标;急流=拉高飞越虚线弧(不经过中间格);撞机=对手飞机沿最短路径滑回机库。
- **侧栏**:当前回合卡(骰子 + 可走飞机 chips)、机队归航(每色 4 架状态:机库/在途/检修/进近/到家)、飞行记录。
- **一屏适配**:沿用 `useGameView`;盘面正方形等比缩放,竖屏侧栏移到盘下。
