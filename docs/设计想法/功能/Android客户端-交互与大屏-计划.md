## 0. 一页摘要

### 0.1 一句话

前两批让 App **在你不用它的时候也有用**;这一批让 **用的时候每一处都更顺手**——手机上「点得准、有反馈」,平板上「用得上屏幕」,系统里「进得来、出得去、找得到」。

### 0.2 三条主线

| 主线 | 要解决的问题 | 对应条目 |
|---|---|---|
| **手感** | 点了像没点、列表操作必须进详情、页面只能重进刷新 | H1 触觉反馈、H2 长按菜单、H3 滑动操作、H4 下拉刷新、H5 分享出口 |
| **大屏** | 平板仍是放大的手机/桌面网页;接了键盘也没快捷键 | T1 大屏判定层、T2–T5 四处双栏、T6 键鼠、T7 拖拽 |
| **入口** | 内容发不出去、找东西只能一页页翻、别的 App 只能分享文字/图片进来 | S1 全局搜索/命令面板、S2「用 ihomy 打开」补全、S3 快捷方式/磁贴扩容、S4 卡片扩容 |

### 0.3 判断口径:什么才值得写原生

| 需求 | Web / WebView 能不能做 | 结论 |
|---|---|---|
| 触感反馈 | ❌ WebView 无 Haptics API(导航栏振动不算) | 一个 30 行的 `IhomyHaptics` 插件(第二批口径延续,不自造大包) |
| 长按菜单 / 滑动 / 下拉刷新 | ✅ Pointer/Touch Events 全部能做 | **前端**,零原生 |
| 平板双栏 / 横竖屏 / 键鼠 / 拖拽 | ✅ CSS + 事件 | **前端**,零原生 |
| 全局搜索 / 命令面板 | ✅ 复用现有列表接口 | **前端**聚合,不新增后端端点 |
| 分享出去 | ✅ `@capacitor/share` 已装 | **前端**,复用现有依赖 |
| 视频画中画 | ⚠ 需要 Activity 声明 + WebView 全屏通道配合 | **原生**,P3 且需真机验证 |
| 老人模式 / 儿童模式 | ✅ 前端皮肤 + 路由守卫 | **前端**;TTS 朗读走系统 `TextToSpeech`(P3) |
| 保险箱自动填充 | ❌ 必须是 AutofillService | **评审制**(第二批 C1 结论不变) |

**一句话**:凡是「碰系统触感/系统 UI 容器」的才写原生,其余全在前端;这一批 P0–P2 只有触觉一项原生。

### 0.4 分期

| 阶段 | 内容 | 估算 | 交付 |
|---|---|---|---|
| **P0** | 手感包:H1 触觉 → H2 长按 → H3 滑动 → H4 下拉 → H5 分享出口 → H6 通知设置入口 | 4–5 天 | 手机上的操作「有回应」,内容能发出去 |

### 0.5 关键决策(定了就不再重新讨论)

| # | 决策 | 理由 | 被否备选 |
|---|---|---|---|
| D1 | **只加「大屏增强层」`isWide`,不改现有 `isTablet→桌面布局` 判定** | `utils/platform.js:55` 的判定已在生产验证;动它等于重排全站,风险与收益不匹配 | 重写 `classifyViewport`、给平板单独一套路由 |

| D6 | **全局搜索先做前端聚合**,不新增后端聚合端点 | 生产 2GB;既有列表接口已带家庭隔离,前端 `Promise.all` 每类取前 5 足够 | 新建 `/search` 跨表端点 |
| D7 | **通知通道不重建**(`reminders-v2`/`family-updates`/`daily-weather`/`app-update` 已存在,参数被系统冻结) | 重建会让用户已调过的通道设置重置;聊天/通知合并成一条是有意设计(固定 id 覆盖) | 拆成聊天/通知两条、按类型再分五条 |
| D8 | **平板双栏只做「列表 + 详情/预览」天然成对的页面**,不做全局双栏外壳 | 聊天是**单个家庭房间**(`views/chat/Chat.vue:6` 只有 `.chat-box`,无会话列表),记账 `BookDaily.vue:582` 已是 2fr+1fr 自适应 → 两者不列入 | 给所有页面加左侧导航栏 |

## 1. 目标与非目标

### 1.1 目标

- **操作有回应**:勾选、长按、拖拽落位、保存成功、校验失败都有对应触感;用户能感到「点到了」。
- **列表不进详情**:提醒完成/推迟、照片分享/收藏、账目复制/删除,长按或滑动即可。
- **平板用满屏幕**:日程月历与当日并排、相册与照片并排、文件与预览并排、书架与详情并排;横屏/分屏自动重排。
- **接上键盘鼠标就能用**:`Ctrl/⌘+K` 命令面板、`Esc` 关层、`/` 聚焦搜索、右键上下文菜单。
- **内容出得去、找得到、进得来**:照片/日记/账目能系统分享;一个词搜全站;别的 App 的 PDF/视频也能「用 ihomy 打开」。

### 1.2 非目标

- ❌ 不改业务口径:提醒/账本/权限/家庭隔离仍以服务端为唯一事实源。
- ❌ 不新增一套权限模型;不因大屏或分享放宽任何可见性。
- ❌ 不做推送(第二批 C2 结论不变,另立计划);不做通知快捷回复(无载体)。
- ❌ 不做原生播放器 L2、不做投屏/地理围栏/扫码/增量更新(理由见 §9)。
- ❌ 不做离线写入;离线仍只有只读与排队提示。
- ❌ 不为平板另写一套页面:同一套组件,靠断点分支。
- ❌ 不做「全局手势导航」(边缘返回等由系统负责)。

### 2.3 必须接受的四个约束

1. **手势卫生**:`AGENTS.md` 前端规范 24 —— 只做意图识别、不 `preventDefault`;横滚容器/输入框/弹窗内不接管。长按与滑动必须与之共存。
2. **动画与响应式**:规范 15/17 —— 拖拽/下拉的位移**直接写 DOM style**,禁止 rAF 每帧写 Vue ref;`computed` 内禁副作用。
3. **平板判定不动**:`useDevice` 的 `isMobile/isPhone/isTablet` 已被导航、主题、布局共用,只**新增** `isWide`/`isLandscape`,不改既有语义。
4. **含原生的版本必须重出 APK**:APK 里的 Web 资源是构建时的 `dist`;`app:sync` 后才能 `assembleRelease`,`external.yml` 的 `latest-version` 必须同步。

## 4. 分期与验收

### 4.1 P0 手感包(4–5 天)

**验收**

1. 勾选一条提醒 → 一次轻触感;系统设置关闭「触感反馈」或 App 开关关闭后不再震。
2. 长按提醒 500ms 弹菜单;手指移动 >10px 取消;行尾「更多」按钮能达到同样操作。
3. 左滑删除账目 → 弹二次确认;在相册横向滑动时不触发滑动操作。
4. 首页下拉出现刷新指示;聊天向上翻历史不触发下拉。
5. 照片查看器「分享」把原图发到微信;无权限/游客看不到该入口。
6. 设置页「通知设置」直达系统通道页,4 条通道可见。

### 4.2 P1 大屏包(6–8 天)

**验收**

1. 10 寸平板横屏:日程页月历 + 当日并排;竖屏掉到 899px 以下自动回单栏,选中日期不丢。

## 5. 详细设计

### 5.1 H1 触觉反馈

**原生**:新增 `frontend/android/.../top/ihomy/app/haptics/HapticsPlugin.java`(插件名 `IhomyHaptics`)。

```java
// 语义 → 系统常量映射(低版本回退 Vibrator.vibrate(ms))
tap      → HapticFeedbackConstants.KEYBOARD_TAP (轻)
select   → CLOCK_TICK / CONTEXT_CLICK(选中/切换)
success  → CONFIRM(保存成功)
warning  → LONG_PRESS(需注意)
error    → REJECT(校验失败)
```

- Manifest 加 `android.permission.VIBRATE`(normal 权限,自动授予,不弹窗)。
- 尊重系统「触感反馈」开关:`Vibrator.hasVibrator()` + `Settings.System.HAPTIC_FEEDBACK_ENABLED` 为 0 时直接返回。
- 前端出口 `src/native/haptics.js`:动态 import,未注册插件时静默 no-op(Web 端零影响);`utils/haptics.js` 做节流(同类 80ms 内合并),开关存 `ihomy:haptics:v1`。
- 接入点(首批 6 处,不铺满):提醒/任务勾选、长按触发、拖拽落位、表单保存成功、表单校验失败、下拉刷新触发。
- **禁止**给滚动、hover、每次点击都加震动。

### 5.2 T1 大屏判定层

`composables/useDevice.js` 增加两个只读 ref(不改既有三个):

```
isWide     = innerWidth >= 900 && min(screen.width, screen.height) >= 600
isLandscape = innerWidth > innerHeight
hasPointer = matchMedia('(any-pointer: fine)').matches   // 鼠标/触控板(不是触屏)
```

- 阈值理由:常见 10 寸平板横屏 ≥1200dp;手机横屏短边 <600 被第二项排除;分屏压窄到 <900 自动回单栏。
- 监听沿用现有 `resize`/`orientationchange`,不新增 rAF。
- 大屏样式统一写在 `styles/main.css` 的 `@media (min-width: 900px)` 段,页面 scoped 里只放栅格本身。

### 5.3 H2 长按菜单 + H3 滑动 + H4 下拉

三个动作共用一个手势仲裁器 `composables/useRowGestures.js`:

| 手势 | 触发 | 取消 | 与现有手势的边界 |
|---|---|---|---|
| 长按 | `pointerdown` 起 450–500ms 定时器 | 位移 >10px / `pointerup` / `pointercancel` | 起手在 `overflow-x` 容器、拖拽手柄、输入框、弹窗内不接管 |
| 滑动 | 水平位移 >36px 且 `|dx|>2|dy|` | 回弹 | 只在纵向列表行、且父级无横滚时启用 |
| 下拉 | `scrollTop===0` 且向下拖 >56px | 回弹 | 聊天/横滑卡片页白名单排除 |

- 位移直接写 `el.style.transform`,不经 Vue ref;结束才提交状态(规范 15)。
- 长按菜单组件 `components/ui/LongPressMenu.vue`:Teleport 到 body,`--z-overlay` 之上按 `zLayers` 标尺,键盘可 Esc 关闭;每行同时给行尾「更多」按钮(`v-a11y-click`),菜单内容与长按完全一致(D4)。
- 滑动操作只接三处首批:提醒行(完成/推迟)、账目行(复制/删除)、通知行(标已读/删除);删除类必须二次确认。
- 下拉刷新只接:首页、通知、相册;**聊天(向上翻历史)、长月历、全屏游戏不接**。

### 5.4 H5 分享出口

新增 `src/native/shareOut.js`:

```
shareText(text, title)                 → Share.share({text,title,dialogTitle})
shareUrl(url, title)                   → 同文本 + url
shareFiles(urls, title)                → 逐张 Filesystem.downloadFile(带 Bearer) → Share.share({files})
```

- 单张 30MB 上限(沿用相册备份口径);多图串行下载(并发 1),下载进 `Directory.Cache`,用完不主动删(系统清缓存)。
- 入口:照片查看器、日记详情、博客详情、账目行「复制摘要」、文件列表「分享」。**只在当前用户有读权限时渲染**(沿用 `userStore`/可见性判断,不新增接口)。
- Web/非壳环境降级为 `navigator.share`(不支持则复制到剪贴板并提示)。

### 5.5 T2–T5 四处双栏

| 页面 | 现状 | 大屏结构 | 关键点 |
|---|---|---|---|
| 日程 `views/schedule/Schedule.vue:47/58` | 月历与当日**纵向堆叠** | 左 62% 月历、右 38% 当日面板,各自独立滚动 | 选中日期双向同步;窄屏保持现有 DOM 顺序(不要用 CSS order 打乱读屏顺序) |
| 相册 `views/album/Album.vue` | 相册网格 → 整页跳 `AlbumDetail` | 左相册列表 280px、右照片墙 | 选中相册走 query/局部状态,**不改路由**;返回键先清选中 |
| 文件 `views/storage/FileBrowse.vue` | 图片/视频走 70% 弹窗 | 右侧 360–420px 预览栏 | 多选模式收起预览;窄屏仍弹窗 |
| 图书馆 `views/library/LibraryList.vue` | 书架 → 整页跳详情 | 左书架、右详情 | 「阅读」仍进 `LibraryReader` 独立路由;不做阅读器内嵌 |

实现约束:

- 一律 `v-if="isWide"` 分支 + 现有单栏组件原样复用,不为双栏重写业务逻辑。
- 双栏容器用 `display:grid; grid-template-columns: minmax(0,1fr) 380px`,列宽可拖动(P1 末尾可选,复用 `useDragResize`)。
- 路由级页面不新增 query 参数就不改 URL,避免「返回」行为变化。

### 5.6 T6 键鼠 + S1 搜索/命令面板

- `composables/useHotkeys.js`:全局 `keydown`,只在 `hasPointer` 或用户显式开启时生效;`event.target` 是 `input/textarea/contenteditable` 时直接返回;`Esc` 只关最上层(与弹窗自带冲突时不抢)。
- 命令面板 `components/CommandPalette.vue`:静态命令(跳转 12 个高频页、新建提醒/记一笔、切主题、打开搜索)+ 搜索结果;`Ctrl/⌘+K` 打开,`↑↓/Enter` 选择。
- 全局搜索 `composables/useGlobalSearch.js`:并发调用既有列表接口(博客/日记/相册/文件/成员/愿望),每类 `size=5`,失败单类降级为空不阻塞;结果标注来源与「查看全部」跳对应页;**不做跨家庭查询**。
- 聊天消息搜索不进首批:WS 只保留最近 200 条(`stores/chat.js` 的 `KEEP_MESSAGES`),搜不全会误导。

### 5.7 T7 拖拽 + S2/S3/S4

- 拖拽复用 `utils/dragInsert.js`;HTML5 drag 只在鼠标下启用,触屏走长按 + Pointer 手动拖影(P1 末尾)。
- S2 Manifest 增量(只列明确类型,不用 `*/*`):

```xml
<!-- 接收文件:PDF / 视频 / 通用文档 -->
<intent-filter><action SEND/><category DEFAULT/><data mimeType="application/pdf"/></intent-filter>
<intent-filter><action SEND/><category DEFAULT/><data mimeType="video/*"/></intent-filter>
<intent-filter><action SEND_MULTIPLE/><category DEFAULT/><data mimeType="application/pdf"/></intent-filter>

<!-- 用 ihomy 打开(VIEW):图片/PDF -->
<intent-filter><action VIEW/><category DEFAULT/><category BROWSABLE/><data scheme="content"/><data scheme="file"/><data mimeType="image/*"/></intent-filter>
```

  落点统一进 `/share`(`views/ShareInbox.vue`),新增「存到文件」「存到视频」两个去向;类型不支持时明说而不是静默失败。
- S3 快捷方式:现有 4 条静态 + 「记一笔 `ihomy://book?new=1`」「新建提醒 `ihomy://schedule?new=1`」「语音记账 `ihomy://book?voice=1`」「搜索 `ihomy://search`」;需要 `router` 支持对应 query 的一次性动作(打开即弹窗,消费后清 query)。
- S4 卡片:新增「记账本月」(`WidgetRepository` 加一路 `/book/summary` 只读,令牌白名单加精确路径);相册回忆卡待 Q8。

### 5.8 明确不做的实现方式

- ❌ 不用 CSS `order` 做双栏重排(读屏顺序错)。
- ❌ 不把长按/滑动写进 `@click` 里(会和 `v-a11y-click` 的键盘事件打架)。
- ❌ 不为搜索新增 `/search` 聚合接口;不做「搜索历史上云」。
- ❌ 不在 `computed` 里做搜索/时间计算(规范 17)。
- ❌ 不重建通知通道、不改 `family-updates` 的合并口径。
