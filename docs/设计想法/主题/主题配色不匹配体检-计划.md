# 主题配色不匹配体检 —— 计划（2026-11-07）

> 状态:**已实施(V11.57,2026-11-07)**。本文是「深色模式下颜色还是浅的」这类问题的**全量清单 + 修复口径**;实施差异见文末 §10。
> 范围：`frontend/src` 全部样式源（220 个 `.vue` + 4 个 `.css`），不含 `public/` 静态资源与 `node_modules`。
> 现行实现以代码为准；本文只记「哪里错、为什么错、怎么改、怎么验收」。

## 0 背景与方法

**主题是两轴**：`theme ∈ { 光尘, 暖居 } × mode ∈ { 晨(dawn), 暮(dusk) }`，`dusk` 打 `html.dark`，`theme-warm` 打 `html.theme-warm`（见 `frontend/src/theme/index.js` 与 `styles/main.css`）。**默认是「暖居·晨」**。

这点决定了严重性：硬编码 Element Plus 浅灰（`#f5f7fa`、`#303133`、`#606266`）不只是深色模式错，**暖居主题下也是错的**——四种组合里只有「光尘·晨」是对的。

**扫描口径**（脚本一次性离线跑，结果未入库）：

1. 解析每个 `<style>` 块的规则（含 `@media` 嵌套，规则级而非行级）；
2. 剥掉 `var(--x, fallback)` 里的 fallback（有变量兜底的不算硬编码）；
3. 对剩余字面量按亮度分类：`background*` 亮度 ≥ 0.62 记「浅底」，`color/fill/stroke` 亮度 ≤ 0.42 记「深字」；
4. 与全树所有含 `dark` 的选择器做类名比对，无交集即「无深色覆盖」。

**数量**：2 176 处颜色字面量 → 286 处「浅底/深字」→ **132 处全树无深色覆盖**，分布 **41 个文件**。按 2026-11-07 拍板后的范围：**在范围内约 70 处**（P0 三组 + P1 + 阅读器 + 自研游戏棋盘/外壳 + 无效变量），其余为已确认不动的装饰与独立产品页（见 §4）。

另做一项独立检查：**引用了从未定义的 CSS 变量**（fallback 静默生效）→ **29 个文件 86 处**，见 §5。

## 3 P1 明细

### 3.1 阅读器：跟随主题色，夜间即深色（`views/library/LibraryReader.vue`）

**现状机制**：`isDark` 由 `document.documentElement.classList.contains('dark')` 驱动，并有 `MutationObserver` 监听 `html` 的 class（L234、L337–339）——**夜间（暮）已经是深色，无需新增开关**。问题在于它自带一套调色板：

| 位置 | 现码 | 后果 |
|---|---|---|
| L786 `.reader-overlay` | `background:#fff; color:#333` | 晨间正确，但用的是裸白/裸灰，与暖居晨的羊皮底色不搭 |
| L795 `.reader-overlay.dark` | `background:#1a1a2e; color:#e8dcc8` | **只有光尘·暮那一套**：暖居·暮打开书仍是蓝黑页 |
| L809 / 847 / 862 / 881 / 909 / 916 / 954 / 1037 / 1040 / 1057 / 1102 | `.reader-overlay.dark .*` 共 11 条 | 顶栏、按钮、目录抽屉、侧栏、PDF 滚动区、翻页箭头、书签项各写一遍深色值 |
| L403–413 `applyEpubTheme()` | `themes.register('dark',{background:'#1a1a2e',color:'#E8DCC8'})` / `('light',{background:'#fff',color:'#333'})` | EPUB 渲染在 iframe 里，**CSS 变量不继承**，只能传字面值 |

**改法**：

1. `.reader-overlay` 底色/字色、`.reader-bar`、抽屉、按钮、箭头、书签项**全部换语义变量**（`--color-bg` / `--color-card` / `--color-text` / `--color-text-secondary` / `--color-border` / `--color-brand`），删掉 11 条 `.reader-overlay.dark` 覆写——深色由 `html.dark` 的变量自动接管，两轴四种组合一次到位。
2. `applyEpubTheme()` 改为**从 `documentElement` 读当前计算值再注册**：`getComputedStyle(document.documentElement).getPropertyValue('--color-bg' | '--color-text' | '--color-brand')`，两套 theme 都用读到的值（`light`/`dark` 名字保留，值随主题）。`MutationObserver` 已监听 class，主题/晨暮切换会自动重注册；**注意**读完值后要 `themes.select()` 再 `themes.override()`，顺序不能反（现在就是这个顺序）。
3. `.pdf-canvas`（L961）白底**保留**——那是 PDF 页面本身；但 `.pdf-scroll` 的外围底色跟主题。
4. `isDark` 保留，仅用于 `applyEpubTheme` 的 iframe 侧判断与图标切换，不再参与配色。
