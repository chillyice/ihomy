# 暖居 · 主题如何落到页面

## 谁决定页面的样子

暖居是站点默认主题，可选外观为暖居与光尘。外观决定装帧与外壳，晨暮独立决定底色、墨色和控件明暗。自动模式按日出日落切换；手动切晨暮会关闭自动模式。旧「窗边」偏好读入后回落暖居。主题注册和切换状态分别由[主题注册表](../../../../frontend/src/theme/index.js)与[主题状态](../../../../frontend/src/stores/theme.js)管理。

站点将暖居标在 `html.theme-warm`，暮色另加 `html.dark`。设备和路由决定使用哪套外壳，常规站内页面另有 `warm-paper-page`。这个类挂在根节点，移到 body 下的菜单和弹窗也能取得同一张纸的底色。[外壳与路由分流](../../../../frontend/src/App.vue)

| 入口 | 页面结构 | 材质落点 |
| --- | --- | --- |
| 桌面与宽平板的家庭页面 | 暖居顶栏、侧栏和内部滚动的主区。首页有可编辑网格，业务页的工具栏可随滚动并入顶栏 | 书布侧栏、书脊折影、卡纸与纸签 |
| 手机家庭页面 | 移动外壳组织首页动态、底栏与子页返回 | 动态卡、上下导航、分组和图标 |
| 纯运维账号 | 运维页面使用专用外壳，桌面与手机按同一套材质组织导航和明细 | 导航用书布，选中项和弹窗标题显纸纹，图表、表格行和固定操作列用实底 |
| 阅读、观影与游戏 | 阅读器、视频和游戏组件负责各自的内容区与全屏操作 | 页码、抽屉标题或文件操作栏 |
| 独立产品页 | 咔哒、比特囊使用自己的外观。壁纸页有独立的主题偏好，可单独选暖居 | 壁纸页自行组织相纸、卡纸与书布控件 |

## 首页、背景与光照各有自己的状态

- **首页布局。** 默认照片、提醒和动态的顺序由暖居首页定义。需要新卡片样式时，在组件注册表声明所属模块、默认尺寸与数据。账号偏好 `home.warm.v3` 保存成员的排版，游客只用本机。检查新样式时同时打开默认排版与一份已保存的旧排版。[暖居首页](../../../../frontend/src/components/warm/WarmHome.vue) · [组件注册表](../../../../frontend/src/components/warm/widgets/registry.js)
- **背景与天气窗。** 外壳底图可用天气图、内置氛围或个人照片。天气卡自己排气温和预报，默认生成图采用写实摄影，用户也可选其他画风。天气读数缺失时显示缺数提示，图片加载失败时仍能读数。桌面背景偏好与天气卡数据分别维护。[外壳背景](../../../../frontend/src/utils/warmBackground.js) · [天气窗](../../../../frontend/src/components/warm/widgets/WeatherWindow.vue)
- **光影与台灯。** 窗棂、树影、盆栽和桌沿物件共用光源与投影关系。物件登记有效高度，由渲染层产生方向性投影。桌面顶栏用日月控件换纸色，光影开启时另有翘板控制台灯，翘板反映灯的实际明灭。手机保留晨暮入口。[全局光影](../../../../frontend/src/components/SunLightLayer.vue) · [桌沿物件接入规范](../../../桌沿物件接入规范.md)

## 给新页面选落点

1. **先跑通原有页面。** 在桌面与手机打开同一路由，找到真实的滚动容器、工具栏与可能挂到 body 的弹窗。首页网格、手机动态和独立产品有各自入口。[桌面外壳](../../../../frontend/src/components/warm/WarmLayout.vue) · [移动外壳](../../../../frontend/src/layouts/MobileLayout.vue)
2. **选承托面。** 一整块低密度内容可用 `.paper-surface`；标题以下都是密集数据时，用 `.paper-heading` 在标题下淡出。已铺纸的工具栏直接复用。照片、输入、金额行、阅读画布保留各自的绘制层。[共享样式](../../../../frontend/src/styles/main.css) · [纸纹、书布与卡纸资产](../../../../frontend/src/assets/materials/)
3. **涉及桌沿时，从行为选物件。** 先核对出现条件、可见数据与点击去向，再选插画。透明底图给出物体自身的体积，长影随现场光向变化。原始试摆稿可用来比对笔触，实际尺寸、避让和投影按接入规范验收。[画风与出图提示词](旧画册水粉材质/窗下桌面与出图提示词.md) · [桌沿试摆样机](旧画册水粉材质/index.html)
4. **验到操作完成。** 桌面滚到工具栏并入顶栏后执行一次操作；平板分屏检查桌沿和正文的点击边界；手机打开照片、阅读器或弹窗再返回。各测晨色、暮色和减少动态效果，保留原始媒体与操作状态作对照。[视觉规范与实页样例](暖居-视觉解析.md)

材质试验的批次、桌沿出图过程和各入口巡检保存在[旧画册水粉材质实施记录](旧画册水粉材质/全站旧画册水粉材质-实施规划.md)。最初用于推敲色温和明暗的[晨暮 HTML 样稿](早期样稿/暖居-晨暮预览.html)与两张 PNG 存于「早期样稿」，供追溯初版设计。
