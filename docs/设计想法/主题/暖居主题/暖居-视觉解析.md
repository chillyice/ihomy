# 暖居 · 色彩、材质与页面样例

## 晨色与暮色

用桌面、纸面、墨色三层建立阅读顺序。晨色靠奶油纸与深褐字拉开距离，暮色靠深胡桃底与浅墨分清层次。主按钮单独取品牌色和按钮文字色。下表是现行样色，组件取同名 CSS 变量。[主题色定义](../../../../frontend/src/styles/main.css)

| 用途 | 变量 | 晨色 | 暮色 |
| --- | --- | --- | --- |
| 桌面衬纸 | `--color-bg` | `#F1E7D6` | `#241A12` |
| 普通卡面 | `--color-card` | `#FBF3E4` | `#33241A` |
| 正文墨色 | `--color-text` | `#4A3A2B` | `#EFE0C8` |
| 主按钮底 / 字 | `--color-brand` / `--color-brand-text` | `#866448` / `#FBF3E4` | `#C9A16E` / `#33241A` |
| 陶土强调色 | `--color-accent` | `#A3564E` | `#E19A8C` |
| 叶绿标记 | `--leaf-accent` | `#6D7F40` | `#A6B784` |

叶绿只要一小处就能标出当前位置，例如当前页签或动态分组的窄横条。收支、告警、禁用和键盘焦点沿用各自的语义颜色和标记。

## 一本画册里的几种表面

| 表面 | 画法 | 放在哪里 |
| --- | --- | --- |
| 亚麻书布 | 用细密织纹透出当下的底色，文字下方压低明暗变化 | 桌面导航、晨暮切换座、手机上下导航 |
| 衬纸 | 细纤维按 128 CSS 像素平铺。大屏多露一截纸，颗粒保持原尺寸 | 页面留白、书脊折影旁的内容底板 |
| 手绘卡纸 | 奶油底上留宽笔触，三种纸样以压痕、纤维和斜刷痕区分。随卡片尺寸伸展中段，固定纸角与边缘厚度 | 首页网格卡、手机动态卡；文字、照片和编辑手柄各自在纸面之上 |
| 薄纸签与相纸 | 短标题下沿显出浅纹，照片外留一圈同色纸边 | 图注、工具栏、分日标题、书签、抽屉标题 |

在相册页，纸纹从封面边缘接到下方图注，停在图像之外。在博客页，同样的薄纸用在目录标题，段落之间靠字距与留白分开。工具栏停在原位时像一条纸签，滚入桌面顶栏后融进顶栏，避免出现两层纸边。[相册与博客实页](旧画册水粉材质/暖居业务页-相册与博客.webp)

## 水粉插画怎么画

以陶杯为母样。机位从正上方看，先用两三块哑光颜色分出杯口、杯柄和碟子，再沿杯沿留几笔断线。缩到 80–120 像素，仍要靠轮廓认得这是一只杯子。画信封时，把同样的笔触用在封口和邮戳上；画便签时，只让一处卷角交代纸的厚度。物件周围留透明，投到桌面上的长影交给现场光照。相纸中央留给真实照片，新物件用下方水粉杯校准视角和颜料颗粒。[水粉陶杯原图](旧画册水粉材质/cup-gouache.webp) · [画风比较与出图提示词](旧画册水粉材质/窗下桌面与出图提示词.md)

## 三种尺度

- **宽屏首页。** 默认十二列里，家庭照片占八列，右侧四列叠放提醒与家人动态。卡片可以换样式、调尺寸。天气卡出现时左侧读温度，右侧风景渐隐进纸色；有家庭天气图就用它，缺图时按天气和昼夜回退到站内风景。图中留出天空或地面，地名与读数由界面排字。
- **平板与分屏。** 按实际内容宽度取景。卡面收窄先减信息，天气卡收起扩展指标，再收预报。桌沿只露得下物件一角时，点击范围也收在可见边缘内，正文仍可选取和滚动。
- **手机。** 首页按动态阅读顺序轮换纸样，筛选条可横滑。书布沿顶栏与底栏收边，「更多」「我的」用旧画册图标配文字。检查安全区、筛选触区以及底栏上方最后一行能否完整点到。[工具目录与手机「更多」](旧画册水粉材质/暖居业务页-工具与手机更多.webp)

## 到哪里收住笔触

做阅读器时，给工具栏和抽屉标题铺薄纸，EPUB 排版和 PDF 页面留给阅读器。照片灯箱只在页码上放短签。播放器留出完整视频和控制条，游戏在文件选择和大厅用纸，开局后让牌桌、棋盘和操作按钮成为视觉中心。切到暮色时，应能顺着控件返回列表。[阅读器桌面晨色](旧画册水粉材质/暖居阅读器-桌面晨色.webp) · [阅读器手机暮色](旧画册水粉材质/暖居阅读器-手机暮色.webp)

检查一页新设计，用同一份数据看晨、暮两态。照片挑一张同时有肤色和暗部的，账本挑有负数和横滚固定列的月份，表单用键盘走一遍。纹理应在纸边可见，固定列应能盖住下面滑过的字，焦点环应穿过深浅边界仍清楚。再关掉光影，确认这些判断依然成立。
