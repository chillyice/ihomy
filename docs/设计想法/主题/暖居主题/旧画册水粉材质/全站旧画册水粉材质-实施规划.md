# ihomy 全站旧画册水粉材质 · 实施规划与交接

> **材质专项记录。** 本文保留最初的三主题样板、分期和后续实页巡检，以便按版本查对。设计新的暖居页面请从[暖居设计理念](../设计理念.md)和[视觉规范](../暖居-视觉解析.md)开始。

**当前进度。** 暖居的首页、日常业务页和手机栏目已接入旧画册材质。首页使用同色手绘卡纸，导航使用书布，业务页在工具栏、分组、图注和浮层使用轻纸纹。晨色沿用奶油纸，暮色沿用深胡桃色。最早的三主题首页样板共用 `frontend/src/assets/materials/paper-grain.webp`，256 像素原图以 128 CSS 像素平铺。

**暖居首页手绘卡纸（V14.24）。** 桌面网格卡与手机动态卡使用完整的空白水粉卡纸插画。纸面保留宽笔触，固定纸角与微翘的纸层厚度，暮色只调整纸色。卡片内容和编辑手柄在纸面上方绘制。16 张侧边插画配有高清 WebP，大屏按实际显示宽度和屏幕密度选图。

## 1. 从哪个版本接手

- 本地基线为 `V14.17`，提交 `009be0e`。这个版本已接入窗下桌面的物件、点击和猫爪印。牛油果绿横条、导航选中态和晨暮叶绿色也已有实现。本轮新增的是承托物件和内容的**页面表面**。
- 画风参考以已选的水粉陶杯为准。取它的哑光颗粒、干笔断边和有限用色。桌面物品自带光向、接触阴影、卷边，整块纸面的纹样只取纤维和颜料颗粒。[陶杯原图](cup-gouache.webp) · [物品画风与提示词](窗下桌面与出图提示词.md)
- 开工先看 `git status --short --branch`、`VERSION` 和最近提交。交接时主工作区另有品牌标识、晨暮图标及部分主题外壳的在途改动，尤其涉及 `WarmLayout.vue`、`WindowShell.vue` 和 `AppSidebar.vue`。以接手时的差异为准，改动按块合并。样板优先从独立业务表面和共享样式切入。
- 窗下桌面开关控制电脑与平板上的小物。平板贴纸可从页缘探入，模态和光影叠在上方。首页纸面直接由主题与组件样式驱动，手机和没有物品的首页也有材质。

## 2. 房间里哪些地方能看见材质

| 表面 | 晨色与暮色的处理 | 具体落点 |
| --- | --- | --- |
| 页面外围与侧栏 | 暖居晨色取奶油纸，暮色取深胡桃底配微亮纤维。光尘降低纸纹强度，让现有冷暖光影透出。窗边沿用自己的明暗底色，颗粒最轻。 | 桌边留白、导航内衬、侧栏与内容之间的分界。天气图存在时把纸感留在框和卡片上。 |
| 封面、卡头与相纸边 | 容许看见干笔收尾，牛油果绿用于窄横条、书签或当前页签。日记可像布脊装订，相册像压在纸页上的照片，日程像翻开的台历。 | 家人动态横条、相册框、日记封面、月历页签。干笔放在少数长期可识别的位置。 |
| 普通内容卡 | 用主题现有卡色托住细纤维。面积越大、文字越密，纹理越淡。 | 日记正文周围、列表头、书架分区、聊天室标题、设置分组。 |
| 金额、输入、原始媒体与沉浸内容 | 实色托住数字、文字和操作状态。照片与视频保留原色，游戏和阅读器保持它们的绘制方式。 | 账本行、固定列、输入框、聊天气泡正文、灯箱、播放器、阅读器、游戏舞台。纸感收在页眉、相纸边、书口或外围工具栏。 |

桌面的大块留白可以露出完整纸面；平板全屏用容器宽度决定显纹面积，分屏后逐步收至卡头、页签；手机以顶部、分组和局部边缘为主。颗粒大小按 CSS 像素稳定平铺。页面变宽是露出更多纸面，手机横屏也要维持合适的颗粒密度。

## 3. 第一批怎么实现

1. **先留对照。** 用同一份演示数据抓取 `/home`、`/album` 和 `/book` 的晨暮截图，记下主题、视口、缩放与光影设置。固定相册封面和账本月份。账本用有可读明细的本地测试家庭，避免用空态代替密集数据验收。
2. **只做一张基础纸纹。** 用可无缝平铺的透明小图，先试 256 × 256 像素、以 128 × 128 CSS 像素重复。图内保留稀疏明暗两种纤维，以便同源地服务晨暮。先拼成 3 × 3，在浅底、深底和手机原尺寸检查接缝、重复斑块与摩尔纹，再压成 WebP。若需要干笔边，另出一小段可横向重复的透明笔迹。资产随组件或样式从 `frontend/src/assets/` 引入，由 Vite 生成带哈希的资源地址。
3. **分开底色与纹理强度。** 在共享样式中提供纸纹图、颗粒尺寸、外框与卡面的强度。底色复用现有语义变量，绿线用 `--leaf-accent`。先给三个样板的目标容器显式加表面类，视觉定稿后再推广到公用卡头、页签或外壳。首页的叶绿横条已有一层线性渐变，各层分别指定尺寸、位置和重复方式，避免背景简写吞掉横条或夜色底。
4. **把纹理画在承托面上。** 普通实底新增一层重复背景即可。只有边饰需要独立透明度时才给局部边缘加伪元素，裁在现有圆角内、设 `pointer-events: none`。图片、文字、焦点环和选择态处于正常绘制层，拖动、横向滚动、缩略图点选与弹窗层级继续由原组件负责。全屏光影仍由 `SunLightLayer` 负责。
5. **检查主题和端的实际入口。** `App.vue` 会选用暖居、窗边、移动端或普通桌面外壳。手机首页和暖居桌面首页有各自组件。显纹面积优先由页面容器和现有媒体查询控制；需判断布局时沿用 `useDevice`，覆盖 ≤768px 的窄窗及 ≥900px 且短边 ≥600px 的宽屏。769–899px 的中间态也单独看一次。
6. **便于局部撤回。** 纹理图变量默认可设为 `none`。把某处纹理关掉后，原底色、绿色提示和交互仍能单独成立。桌边物件开关、相册数据与权限、路由、数据库均沿用现有实现。

可从下面的 CSS 结构试起。名称是提案。示例用于已有实色、没有背景图的卡头，遮色层与卡色同源，所以调浓淡只影响纸纤维。

```css
.paper-card-head {
  --paper-base: var(--color-card);
  --paper-veil: color-mix(in srgb, var(--paper-base) 70%, transparent);
  background-color: var(--paper-base);
  background-image: linear-gradient(var(--paper-veil), var(--paper-veil)), var(--paper-grain, none);
  background-size: auto, var(--paper-tile, 128px) var(--paper-tile, 128px);
  background-repeat: no-repeat, repeat;
}
```

**纸纹出图提示词，可交给美术或图像工具复用**

> 为 ihomy 的旧画册水粉页面制作一块可上下左右无缝平铺的细纸纤维。取参考陶杯表面的哑光水粉颗粒，视线正对纸面，光照均匀。零散短纤维与微细颜料点疏密自然，中心和四边的明度、密度一致。透明底，明暗两种低对比颗粒，适合叠在淡奶油色和深胡桃色上。画面只含平整纸面肌理。排除物件、文字、边框、折角、投影、渐变光斑、大片污渍和可辨认的重复图案。

| --- | --- | --- |

| 入口 | 纸纹落点 | 内容区处理 |

| 设置、登录、帮助、存储及公共浮层 | 设置分组、登录卡、文件预览栏、下拉菜单、命令面板底栏；运维页签使用书布 | 表格固定列、表单控件与媒体预览保留实底和焦点反馈。 |

暖居普通页面使用 `.paper-surface` 为一整块承托面铺薄纸，或使用 `.paper-heading` 让纸纹在标题下沿淡出。新增组件时先看已有工具栏和分组标题是否已经绘制纹理，避免父子同时在同一片区域叠纹。

- **主题与尺寸。** 三主题各看晨、暮；代表视口可取 1440 × 900 桌面、1024 × 768 平板横屏、768 × 1024 竖屏/分屏、820px 宽的中间态和 390 × 844 手机。检查实际布局切换、系统字体放大、窄屏横滚与触摸。Web/PWA 共用前端，壳内验证用包含本次前端的安装包；将模拟检查和真机结果分别记录。
- **内容与交互。** 同一张照片在灯箱里的图像区域与基线对照，检查自然肤色、白色和暗部。账本横滚时固定列维持实底，金额符号、负数、收支颜色和键盘焦点仍易读。首页可拖动卡片，桌边物件支持键盘与鼠标点击。打开弹窗、抽屉和遮罩时光影层级正确。
- **性能与交付。** 用静态平铺控制绘制成本。在手机上滚过长列表、切晨暮、打开照片后返回，同时观察光影开启和关闭两种状态，检查是否闪烁或成片重绘。检查 Network 与构建产物中的纹理尺寸、传输字节和重复请求。运行仓库的构建验证与轻量收尾；对照 V14.17 的首屏静态 JS 基线（42 个，1489.22 KiB）。记录样板截图、已验页面和设备、剩余个别适配及原因，供下一批复用。
