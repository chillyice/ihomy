## 重新生成

前置条件：Python 3（需 `pypdf`）、Node.js 20+、本机安装 Edge 或 Chrome。

```bash
cd C:/Users/chill/OneDrive/WorkStation/Projects/ihomy
python scripts/soft-copyright/build_source_doc.py
python scripts/soft-copyright/build_manual_doc.py
```

说明：

- 版本号自动读取仓库根 `VERSION`，输出文件名随之变化。
- 软件全称、文档标题在 `scripts/soft-copyright/build_source_doc.py` 与 `build_manual_doc.py` 顶部常量中维护；改动后两份 PDF 的页眉会同步更新。
- 用户手册正文来自 `scripts/docs-gen/manual_part1..3.json`（项目维护的用户手册内容）；修改内容后重跑即可。
- HTML → PDF 通过 Chromium DevTools 协议完成，生成器为 `scripts/soft-copyright/print_pdf.mjs`；无需安装 LibreOffice。
- 生成脚本会自检页数与溢出，失败时以非零退出码结束。

## 提交步骤

1. 在「中国版权保护中心」官网注册账号并完成实名认证，进入软件著作权登记系统。
2. 按 `软件著作权登记-申请信息表.md` 逐项填写；带【待填】的身份信息需申请人本人补充。
3. 上传两份 PDF：源程序与文档各 60 页。
4. 上传身份证明（个人：身份证正反面；单位：营业执照副本加盖公章）。
5. 提交后按系统提示签字/盖章、缴费（登记费已停征，以最新公告为准）并等待审查。

## 注意事项

- **名称与版本必须一致**：申请表、源程序页眉、文档页眉三处逐字一致；改版本后必须重跑两个脚本。
- 本次按**独立开发、原始取得、全部权利**填写；如实际为合作开发、委托开发或职务作品，需相应调整并提供协议/证明。
- 生产站点已上线，申请信息表按「已发表」填写；首次发表日期以实际可查的最早生产记录为准，若不确定可选择「未发表」。
- 仓库当前为 GPL-3.0 许可，不影响著作权归属与登记；如后续调整许可，请单独评估。
- 若审查员要求单一编程语言版本，可临时把 `build_source_doc.py` 的 `collect()` 改为只收集后端或只收集前端，再重新生成 60 页。
