## 三、开发目的

为家庭成员提供一个私密、易用、跨设备的数字空间，把日常记录、照片影像、家庭事务与协作工具集中在一处，解决家庭成员之间信息分散、回忆难以沉淀、跨设备体验不一致的问题。系统以家庭为单位隔离数据，按家长、成员、孩童、访客分级授权，让不同年龄的成员都能低门槛参与记录与共享。

## 五、技术特点

1. **前后端分离与三端一致**：前端 Vue 3 + Vite + Element Plus + Pinia 构建 PWA，同一套代码适配电脑浏览器、安卓与 iOS；后端 Spring Boot 4（JDK 21 虚拟线程）+ MyBatis-Plus 提供 REST 接口。
2. **家庭级数据隔离与分级权限**：业务数据按 `family_id` 隔离，OWNER/MEMBER/CHILD/GUEST 四级家庭角色 + 独立运维角色 OPS；权限码 + AOP 注解鉴权，跨家庭访问统一返回不存在。
3. **双令牌认证与自动续期**：access token（2 小时）+ refresh token（7 天），刷新即轮换并拉黑旧令牌，前端请求前预检过期并自动续期。
4. **沉浸式光影系统**：后端按真实太阳方位与高度计算日出日落与直射点，前端以球面几何渲染窗边体积光、台灯夜光与天气粒子，光照随时间和天气连续变化。
5. **户型图与物品坐标定位**：自绘房子/房间/家具三级平面图，物品落在真实坐标上；支持多楼层、PDF 底图标定、家具库拖放与手机只读浏览。
6. **配置驱动的模块化首页**：首页模块由数据表配置排序与显隐，新增功能只需增加一条模块记录；工具箱由注册表统一维护元数据，前端零框架改动。
7. **实时通信与协同编辑**：WebSocket 承载聊天室消息与未读计数；协同脑图采用乐观锁 + 轮询裁决，支持历史版本快照与回滚。
8. **全链路可观测与数据安全**：traceId 贯穿 HTTP、WebSocket 与异步任务，访问/服务/三方日志按天滚动；密码与业务凭证 AES-GCM 加密，令牌黑名单与接口限流防爆破；81 张表统一逻辑删除并提供回收站。

5. **不含敏感信息**：已检查提交页，未包含生产密码、密钥、Token 或数据库连接串。
6. **开源许可**：仓库当前使用 GPL-3.0 许可，这只影响代码的分发方式，不影响著作权归属；登记不改变既有开源许可，如后续需要调整许可，请另行评估。

8. **电子申请**：在「中国版权保护中心」官网注册并完成实名认证后，进入软件著作权登记系统在线填写、上传 PDF 并提交；是否需要邮寄纸质材料以系统提示为准。
9. **常见退回原因**：页眉缺名称/版本/页码；页数或每页行数不足；名称/版本不一致；源程序含第三方代码；申请表与身份证明信息不一致；文档无页码或页码不连续。
