- 决策:
  - 预警类型图形**直接复用和风 code**(国内 1001–1089、国际 2001–2084 与图标库同号),不再自建类型→图形映射表;未知类型统一回退通用预警图标 `9999`。
  - 多条预警不再横向滚动堆叠:右起 + 滚动在窄屏会互相遮挡,且初始滚动位置各浏览器不一致;「一条给全貌、多条给信号、点开看详情」信息层级更稳,也去掉了滚动容器。
  - 侧栏预警图标用内联 SVG 而非 Element Plus 图标:复杂 path 在 100% 缩放下光栅化发虚(前端规范 5);`WarnTriangle` 用 `useId()` 生成 `mask` id,同页多处复用不会串形。
  - 胞吐判定必须带**迟滞**:单一阈值在临界页高上会循环「胞吐 → scrollTop 被夹回顶部 → 收回 → 再胞吐」,表现为内容上下跳动;收回线要在胞吐线之下再让出 `loss`,`scrollTop` 落在区间内保持不动。
  - 页面短到「省不出一次胞吐」时(切到只有几条记录的月份)必须强制收回,否则工具栏钉在顶栏里永远回不去。
- 接口/表/路由变化:无。
- 踩坑:
  - 工具栏可能**晚于进页渲染**(外壳工具栏先出、页签工具栏后出),进页那一刻量到的 `pinLoss` 会少算;换页后要把缓存归零重测,否则短一截的 `loss` 会让收回线偏上、显示反复。
  - 胞吐把工具栏搬出内容流后,页面总高同步少掉 `loss`;不按 `scrollHeight - clientHeight` 判断就出现「往下翻又弹回来」。
  - `new Date('2026-11-07')` 按 UTC 解析,在非 +08:00 环境取周几会偏一天;日期只取 `yyyy-MM-dd` 数字段后本地构造。
  - 隐藏/切换标签页时 `getComputedStyle` 可能读到过渡起点色(与本条同批的配色复测结论一致),样式断言前要先 finish 动画。
- UI 细则:预警信号 = 级别色底 + 和风类型图形 + 类型名,单条 `58px` / `compact` `46px`;黄、白两级用深色字(`#3a2e22`),其余白字;10 天预报单列,宽屏温度横条上限 `280px`,超窄屏退化为纯数字;暖居胞吐只作用于 `.page-toolbar`,阈值与收回线由 `nextScrolled` 统一判定。
