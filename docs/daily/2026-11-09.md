## 15:47 光影层彻底去掉 `mix-blend-mode` 与整页遮罩,全部改普通 alpha 叠加(V11.72)

- 现象(用户 V11.71 复测):V11.70 有一次冷启动正常、V11.71 仍黑——说明是**偶发的 GPU 合成失败**,不是某条规则确定性命中;V11.71 只去掉了 `filter: blur()`,但光影层还留着 5 张全屏 `mix-blend-mode`(multiply×2 / soft-light / screen×2)与暖居主区的整页 `mask-image`。
- 变更:`frontend/src/components/SunLightLayer.vue` 把 `bright-spot`(multiply)、`window-shadow`(multiply)、`reflection-layer`(soft-light)、`light-layer`(screen)、`dust-layer`(screen)、`lightning-flash`(screen)全部改回普通 alpha,并去掉各层 `transform: translateZ(0)`(不再每层强制一整套全屏纹理);`frontend/src/styles/main.css` 删掉 `html.theme-warm .gc-main` 的整页滚动边缘 `mask-image` 与 `html.booting` 相关规则;`frontend/index.html` 删掉 `html.booting` 的内联脚本;`frontend/src/utils/windowLight.js` 的 `reflectionOpacity` 系数 0.22 → 0.12(soft-light 改 alpha 后按观感折半)。
- 决策:窗影/天气阴影是 `rgb(0,0,0)` / `rgb(8,12,28)`,**multiply 与普通 alpha 在米色底上几乎完全等价**(纯黑时数学上相等),所以这两层零视觉损失;screen 的光柱/浮尘改成 alpha 后从「叠加增亮」变成「暖色薄纱」,亮度略降但光影形状、位置、颜色全保留;暖居主区上下 40px 的边缘渐隐是纯装饰,直接放弃换取稳定。目标是让光影层**不再有任何全屏背景回读(blend)、离屏纹理(filter)与整页遮罩(mask)**。
- 踩坑:`mix-blend-mode` 不是「一层换个颜色」那么简单——它要求合成器为每个混合层读一遍整屏背景,5 层叠加就是 5 次全屏采样;再叠加 `transform: translateZ(0)` 给每层单独分配视口大小的纹理,低端显卡 + 冷启动(启动页)时显存/合成器管线最容易崩。`mask-image` 同理,整页尺寸的遮罩会让所在元素整体进离屏表面。
- 验证:`npm run lint` 0 error;`npx vitest run` 884 passed;部署 V11.72 后清 SW 缓存重载:页脚 `ihomy V11.72`,`.sun-light-layer` 内 **`mix-blend-mode` 非 normal 的元素 0 个、`filter` 非 none 的 0 个**,`.window-shadow` 为 `overflow: hidden` 且 `blend: normal`,`html.theme-warm .gc-main` 的 `mask-image` 为 `none`,控制台无 error。
