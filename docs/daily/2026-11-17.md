## 19:50 早安随机云:按云型定边界硬度并抬对比,云在照片上真正有轮廓(V12.72)

- 背景:随机云画出来和天气照片糊成一片,几乎看不出云形。真因是照片天空亮度约 130–150,而云团中间调也落在同一区间,加上每层渐变都按同一条「5 段柔化」曲线收尾,云没有轮廓可依。
- 变更(`frontend/src/components/morning/RandomClouds.vue`):
  - **色调抬对比**:新增 `cloudTone()`,亮部朝白推 0.55、暗部压深(夜态朝 `[16,22,34]`、日态朝 `[58,70,88]`)各 0.5,只保留色相;亮部靠亮度压住天空、云底暗部成为真正的轮廓层。
  - **边界硬度成参数**:`blob()` 增 `soft`(默认 0.55 = 旧曲线),梯度 5 段的位置与透明度随 `soft` 联动(0.15 利落边、0.95 无边);新增 `KIND_SOFT` 按云型给值(积雨云 0.16 / 积云 0.24 / 卷云 0.34 / 高积云 0.32 / 层积云 0.5 / 雨层云 0.84 / 层云 0.9 / 雾堤 0.98),积云的云顶比云底硬、层状云刻意不收紧。
  - **外层模糊按硬度缩放**:`cvBlurRatio(kind, factor) = factor × (0.45 + KIND_SOFT[kind])`,`minBlur` 兜底从 7 降到 2(硬边云不再被最小模糊抹平)。
  - **尺寸与不透明度整体上调**:`KIND_SHAPE` 八种的 `w`/`px`/`op` 全组抬档、`blur` 收窄(例:积云 `w` 44–88 → 52–96、`op` 0.46–0.86 → 0.72–0.98、`blur` 0.026–0.05 → 0.012–0.024;薄云仍留 0.5 起步)。
- 决策:①不用「加一层蒙版/SVG 形状」的路线,继续在单元素多层径向渐变里做:一朵云仍是一个 DOM,元素数与动画成本不变。②硬度按云型(自然规律)而不是按每朵随机:同屏积云与层云本来就该一个利落一个化开;同朵云内再按层微调 ±0.04。
- UI 细则:云要压在天气照片上,判断标准不是「云色像不像天空」,而是**云的暗部能不能和照片天空拉开亮度差**;层状云允许没有边界,个体状云不允许。
