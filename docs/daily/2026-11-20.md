## 15:35 修复:退出游戏后悬浮 BGM 停不下来(V13.90)

**现象**:首页 BGM 在播 → 进游戏 → 按外壳静音键 → 退出游戏,音乐自己响回来,再想停也停不住。

**根因(V13.88 引入)**:`MusicPlayer.vue` 把 BGM 绑成 `:muted="gameMuted && route.path.startsWith('/games')"` —— 静音只是把音量压到 0,进度照常往前走;一旦离开 `/games` 路由表达式变假,静音被自动解除,那首「听不见还在放」的歌就接着响,用户视角就是「静音了还停不下来」。

**修法**(`frontend/src/components/MusicPlayer.vue`):
- 去掉 `:muted` 绑定与 `silencedByGame`;静音键对 BGM 改为**真暂停**:`watch([gameMuted, inGames])`,在游戏页且静音键开着就 `pause()`,进度不走、不再悄悄续播。
- 用 `pausedByMute` 记住「这次是静音键停的」:只有把静音键关掉才接着放;**离开游戏页(静音键仍开着)保持停**,不再自动响回来。
- 用户自己按过播放/暂停(或切歌后自己起播)后 `pausedByMute` 清空,静音键不再替他接管播放。
- 进游戏不按静音键时不动 BGM(沿用当前播放状态,与既有口径一致)。

**浏览器实测**(dev 5173 + 开发库临时歌单,验完已删):进游戏 BGM 照播 → 按静音键 `paused=true` 且 `currentTime` 停住 → 返回 `/games` 仍暂停 → 回首页仍暂停、播放器显示「已暂停」→ 自己按播放恢复 → 静音键仍开时再进游戏又停 → 取消静音接着放 → 未静音退出照播。

**验证**:`vitest run` 1507 passed / 130 文件;`eslint`/`prettier --check` 干净;`npm run build` 通过(构建时并行会话的 Doudizhu.vue 正在改,首跑失败,其修好后再跑通过);本次只动 1 个前端文件,未触碰并行会话的 games 改动。开发库 `content_music_playlist(id=1, __bgm_probe__)` 及 track 行已删除。

## 16:05 改口径:BGM 改成「只属于游戏」——进游戏从头播、退出彻底停(V13.91)

**用户口径修正**:上一版(V13.90)把游戏里的 BGM 当成「首页音乐在游戏内暂停」,用户要的是反过来——那首歌只在游戏里放:

- **进游戏**:从**开头**播(不接上次进度)。
- **退出游戏**:音乐**完全停止**(暂停 + 进度归零),不是留个暂停位等回来接着放。
- **重新进游戏**:重新从头播。
- **静音键**:只负责「播 / 不播」,不背别的语义。

**改法**(仍只动 `frontend/src/components/MusicPlayer.vue`):
- 判定收紧为 `inGame = route.path.startsWith('/games/')` —— `/games` 列表页不算游戏,不接管播放。
- `watch(inGame)`:`true` → `currentTime = 0` 后 `play()`;`false` → `pause()` + `currentTime = 0`(彻底停,回不来)。
- `watch(gameMuted)`:静音就 `pause()`,取消静音就 `gameBgmArmed = true` 再 `play()`(游戏内才有效)。
- `gameBgmArmed` 兜底:硬刷新/深链直接落在游戏页时,歌单、曲目、签名地址、`<audio>` 元素都比路由晚到——`watch([playSrc, playlist.length])` + `nextTick` 补一次起播;浏览器拦自动播放时,再等页面里第一次 `pointerdown`/`keydown`(捕获阶段,真手势)补一次。
- 用户自己按播放器上的播放/暂停即清 `gameBgmArmed`,静音键不再替他接管。

**浏览器实测**(dev 5173 + 开发库临时歌单,验完已删):
| 场景 | 结果 |
|------|------|
| 硬刷新直接落在 `/games/petlink` | 自动起播 `t=0→3.7` |
| 游戏内点静音 | `paused=true`,`t` 停住 |
| 再点取消静音 | 从停的位置接着放 |
| 返回 `/games`(列表) | `paused=true,t=0` |
| 重进同一游戏 | 从头播(`t≈1.5`) |

| 回首页 | `paused=true,t=0` |
