## 00:10 纸牌翻牌/发牌动画:3D 真翻动 + 牌堆飞牌到位(V13.50)

- 反馈(原话):「纸牌在翻牌以及发牌的时候,增加动画效果,比如翻牌像是真正的翻动,发牌是直接发到目标位置上」。
- 变更:
  - **3D 翻牌**:新增 `views/games/cards/CardFlip.vue`(双面结构,正面懒挂载:首次翻开后常驻,撤销翻回背面也能动画,且避免开局就加载全部 52 张牌面图);`cards.css` 新增 `.sol-flip/.sol-face/.is-down` 规则(`.sol-cardface` 加 `perspective: 900px`,背面花纹从 `.sol-cardface.back` 移到 `.sol-face-back`,`back` 类只留 touch-action)。规则引擎在 `move()` 里翻面、`cloneState` 保留 id(v-for 键稳定),faceUp 变化 → class 切换 → CSS transition `rotateY(180deg)↔0` 420ms 自动出真翻牌。Klondike 废牌堆/花色堆/桌面列、Spider 桌面列接入;FreeCell 无背面牌不接(渲染不变)。
  - **发牌飞行**:新增 `utils/games/cardAnimations.js`(FLIP:`dealtIds` 按牌堆差集取发出的牌(堆顶先发,倒序)、`flyCardsFrom` 用 WAAPI 把新牌从牌堆 slot 位置平移回起点再飞到位,`fill:'backwards'` 让未起飞的牌先停在牌堆上,飞行途中临时抬 `z-index:60` 压过相邻列、`anim.finished` 还原;`prefers-reduced-motion` 跳过)。接线:Klondike `draw()`(1~3 张,stagger 110ms)、`startNew()`(28 张,24ms);Spider `dealRow()`(10 张,42ms)、`startNew()`(54 张,14ms)。牌桌牌面加 `data-card-id` 供按 id 查 DOM。
  - **假翻转守卫**:挂载时先渲染 `deal(1)` 占位再 `loadState()` 换存档,同 id 牌 faceUp 重排会触发一串凭空翻转(实测复现:两张占位局正面/存档背面的牌在载入时翻转)。两块棋盘加 `boardReady`(根节点 `.sol-no-anim`),`onMounted` 末尾 `nextTick + 60ms` 后放开;`.sol-no-anim .sol-flip { transition: none !important }`。发牌飞行是 WAAPI 不受影响,开局照常飞。
- 决策:翻牌用「双面常驻 + class 切换」而不是 JS 逐帧,过渡由合成器驱动(前端规范 4:一次性动画 CSS 优先);发牌量终点矩形在渲染后(nextTick)再量,规避首帧布局未定;`gameShellAdoption.spec` 的 CARD_BOARD 名单补登记 `CardFlip.vue`(守门按目录扫 .vue)。
- 验证:
  - `npm run lint` 0/0、`npx vitest run` **1437 passed / 124 文件**(含新增 `cardAnimations.spec.js`:flyOffset/dealtIds)、改动文件 prettier 干净。
  - IAB(dev 5173)合成事件实测:开局「新游戏」三步后 **28 张起飞**(delay 0..648 递增、`translate(-102,-150)` 从牌堆反转、fill backwards);抽牌 1 张从牌堆飞进废牌堆(`translate(-108,0)`);Spider 开局 54 张(14ms 递进)+ 发一排 10 张追加;翻牌走步后 `.sol-flip` 过渡 `rotateY(180deg)→0` 420ms 创建、正面懒挂载生效;守卫后载入期 sol-flip 过渡 **0 个**、60ms 后守卫解除、真走步翻牌照常创建。注意:本 IAB 的 document timeline 不推进(rAF 不派发同源怪癖),动画只能验到「创建/关键帧/清理」级,play 级在真机浏览器成立;`anim.finished` 清理路径用 `finish()` 侧验通过(z 还原、transform 回位)。

## 00:35 对抗牌局选牌交互:选中弹起 + 手机滑动多选 + 右键直出失败塞回(V13.51)

- 反馈(原话):「掼蛋、斗地主、保皇这类游戏,在选择纸牌的时候,选中卡牌的效果是纸牌向上探出一块。在手机上支持拖选多个,通过手动滑动即可。电脑上,鼠标左键滑动是多选,右键滑动是选中后,在自己出牌时直接出牌。如果无法出牌,那么就将手牌塞回,不再探出。」
- 变更:
  - **选中弹起**:`components/games/FightTable.vue` `.ft-card.sel` 加 `transform: translateY(calc(-1 * var(--fc-pop)))` + `z-index: 2`(负 margin 叠牌下抬层保描边完整可见);`--fc-pop` 竖屏 14px / `max-height:520px` 短屏档 9px(与 `.ft-hand` padding-top 余量匹配,不被 overflow 裁);走既有 0.14s transform 过渡,取消/塞回自动回落。四局共用组件一次生效(含够级)。
  - **手机滑动多选**:`onCardDown` 放开 pointerType(touch/pen 按左键「扩选」语义,鼠标右键仍 auto-select);拖选会话记 pointerId 多指守卫(move/up 只响应该指针,第二根手指不起会话不拆监听);阈值分档鼠标 6px / 触摸 10px(手抖超阈值会把「点选取消」误判成拖选——拖选起点牌是并入选择,方向相反);`.ft-card` `touch-action: none` 防浏览器接管滚动。
  - **手牌恒适配(拖选前提)**:`.ft-my-area` 开 `container-type: inline-size`,步长改 `clamp(7px, calc((100cqw - 12px) / (n + 1.15)), 30px)`(旧公式 `100vw/n` 恒溢出 1.1 步、横屏左栏布局必溢),`--fc-card-w` 下限 30→16px——保皇 34 张在 390×844 竖屏实测 scrollWidth=clientWidth 无横向滚动,触摸滑动才不会被滚动手势抢走。
  - **落点探测改 `elementsFromPoint`**:弹起牌带 `z-index:2` 会盖住未选右邻条,elementFromPoint 命中已扫过的牌即跳过导致漏选(手机 10px 步长实测复现);改为自上而下找「最上层且本次未扫过」的牌。
  - **右键直出失败塞回**:四页(`Doudizhu/Guandan/Baohuang/Gouji`,`tryAutoPlay` 同构块)在 myTurn && !canPlay 分支清空 `pendingAuto` + `selected`(旧版保留选中退手动);非自己回合右键预选仍弹起预览,轮到自己自动打出或塞回。
  - **extendSelect 手牌过滤**(四页):拖选途中 AI 换手重排会让扫过的旧 id 残留 `selected`,同 id 牌再现被意外点亮(手机实测复现);并入前过滤到当前手牌。
  - **i18n**:`games.fight.gestures`(zh/en)一行手势说明,四局 `#rules` 列表各追加一条。
- 决策:不抽 composable(每页改动 3-4 行,保持页面自治结构);拖选起点牌在过阈值时并入选择、5px 内手抖仍走点选 toggle(与主流手机斗地主一致);触摸阈值 10px 独立于鼠标 6px。
