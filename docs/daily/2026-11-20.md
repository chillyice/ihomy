## 13:05 手机横屏牌桌「不要/提示/出牌」在浅色主题下压在绿毡上看不清(V13.81)

- 变更:`frontend/src/styles/main.css` 对抗牌局段的横屏矮屏档(`orientation:landscape` + `max-height:520px`)补四条规则——`.ft-actions` 里的次级键(不要/提示/叫分)与头部次级键同一套白玻璃(底 `rgba(255,255,255,.14)`、hover .22、字 `#fff`);禁用档 `.is-disabled` 退回 .08 底 + .6 白字;主按钮「出牌」禁用档 .12 底 + .65 白字,启用态仍是品牌色。
- 踩坑:横屏矮屏那一档整页铺深绿桌毡(`--gs-bg` 换成线性渐变),只把 `.gs-head` 次级键和白牌区文字(`.ft-my-head`/`.ft-my-name`)改成了浅色,**漏了同一张毡面上的 `.ft-actions`**。浅色主题给次级键的是「`--color-line`(10% 暖褐底)+ `--color-text` 深褐字」,压在深绿上实测对比度约 **1.05:1**(深字压深底);深色主题本来就是白玻璃,所以只有浅色模式暴露。竖屏与桌面的操作栏落在浅米页底(`gc-studio` `#f1e7d6`),同一套颜色没问题——故只在横屏毡面档修,不碰全局禁用态。
- 踩坑(验证):IAB 里量 `getComputedStyle` 会读到旧值——`.el-button` 的 `transition: background .2s` 被冻结在 `currentTime=0`,必须先 `el.getAnimations().forEach(a => a.finish())` 再读;color 不参与该过渡所以已是新值,不处理时读数会「半新半旧」。
- UI 细则:禁用态要压过「主题非主按钮」那条(浅色主题里它特异性更高,禁用键会被刷成常态色),选择器必须带满整串 `:not()` 再接 `.is-disabled`;牌桌毡面上的按钮一律「白玻璃 + 白字」,禁用退回低透明度白。
