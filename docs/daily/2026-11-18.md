## 02:30 家庭切换多端隔离(V12.80)

- 变更:同一账号多设备登录时,一台设备切换家庭不再把其他设备的会话带过去。
  - 根因:switchFamily 写的 Redis `user:curfamily:{userId}` 是按用户的键,而 `refresh()` 续期时走 `familyOf()` 重新解析(全局 Redis 最近家庭优先),设备 A 切换后设备 B 下次续期(≤2h)即被带走。
  - 修法:**家庭快照随刷新令牌携带**——`generateRefreshToken/generateWallpaperToken` 增加家庭入参;`AuthService.refresh()`(含轮换宽限重放路径)优先用令牌自带家庭,令牌无快照(7 天内残留旧令牌)或已不是该家庭成员(被移出)才回落全局解析;`switchFamily` 仍写全局 Redis 最近家庭,但语义收窄为**登录偏好**(重新登录进入最近切换的家庭);`/auth/families` 的 isCurrent 改按本会话 JWT 家庭标记(`listFamilies(userId, sessionFamilyId)`),多端各自高亮。`JwtUtils.java` / `AuthService.java` / `AuthController.java`
- 接口变化:`/auth/families` 响应里 isCurrent 口径变化(全局最近家庭 → 本会话家庭);无新增端点、无表变更。
- 决策:
  - 登录偏好保持全局(进「最近切换」的家庭):存量会话隔离是本次诉求,重新登录落在哪个家庭属产品语义,单设备用户行为不变;若要登录偏好也按设备需前端记住家庭再传后端,另行设计。
  - setDefault(设为默认)仍是账号级显式动作,不变。
- 验证:新增 `AuthServiceFamilyScopeTest` 5 例(令牌家庭沿用/移出回落/宽限重放/switch 签发快照/isCurrent 按会话);后端全量 427 tests 全过(基线 392 + 并行会话与本批新增);前端零改动(令牌本就按设备存储)。
