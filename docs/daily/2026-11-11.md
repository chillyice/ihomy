## 18:59 V12.3 一次性铺齐 iOS 客户端(13 插件 + 三 target + 平台门禁改造)

- 变更:新增 `frontend/ios/`(Capacitor 8 + SPM,无 CocoaPods),三个 target:`App`、`IhomyWidgets`(WidgetKit)、`IhomyShare`(分享扩展)。13 个 Swift 插件与 `src/native/*.js` 的 `registerPlugin` 同名同参:`IhomyBiometric / Haptics / Screen / Call / Speech / Camera / Calendar / PhotoBackup / Share / Diagnostics / Widgets / Updater / Pip`,全部在 `MainViewController.capacitorDidLoad()` 注册。共享代码集中 `IhomyShared.swift`(App Group `group.top.ihomy.app`、`IhomyAPI`、`IhomyWidgetStore`、`IhomyWeather`、`IhomyNotify`、`IhomyBackground`、`IhomyShareStore`、`IhomyCrashStore`),三 target 共用;两个扩展是独立进程,不加载 Capacitor。另加 `frontend/ios/README.md`(target 结构、13 插件 ↔ JS 对照、深链链路、pbxproj 手工注入的注意事项)。
- 能力对照(Android → iOS):APK 自更新 → App Store(`status().canInstall` 恒 false、`getAutoUpdate` 恒关);下拉栏磁贴 → iOS 无对应物,如实不做;30 秒常驻前台服务 → `BGAppRefresh`(标识 `top.ihomy.app.refresh`,系统调度、不保证 30 秒)。其余 1:1:生物识别(Face ID / Touch ID)、触感(`UIImpactFeedbackGenerator` 五档)、防截屏(切后台/录屏遮罩,App Store 规则下无法真正阻止)、通话权限、语音识别(`SFSpeechRecognizer`)、拍照(`UIImagePickerController`)、系统日历读写(EventKit,iOS 17 走 `requestFullAccessToEvents`)、相册备份(PhotoKit 增量)、分享扩展、诊断(崩溃日志落盘)、四张 WidgetKit 卡片、画中画(`webkitSetPresentationMode`)。
- 接口/配置变化:后端 `AuthCookie` 同时接受 `capacitor://localhost`(iOS WebView origin)与 `https://localhost`(Android),`SameSite=None; Secure` 口径不变;`app.cors-allowed-origins` 追加 `capacitor://localhost`(`application.yml` + `external.yml.template`)。iOS 壳**不设** `server.iosScheme`,默认 origin 即 `capacitor://localhost`,不改名以免与 Android 分叉。`Info.plist` 新增 `IHOMYApiBase`(默认 `https://ihomy.top/api`)给后台刷新显式配置,`UIRequiredDeviceCapabilities` 由模板的 `armv7` 改 `arm64`(部署目标 15.0,只有 arm64 产物)。表结构无变化,无 live SQL。
