## 21:40 天气页温度排版防换行 + 雾效果改高斯噪声并几秒消散（V12.25）

- 变更①（实况温度排版）：`frontend/src/views/weather/Weather.vue` 实况读数行拆成两组——`.wt-readout`（大图标 + 大温度，`inline-flex` + `white-space: nowrap`，永不拆行）与 `.wt-aside`（今日高低温 + 天气文字，空间不够时整组换到下一行）。此前单层 `flex-wrap: wrap` 在文字被放大或内容区被压窄时会把温度挤到图标下方，变成上下排版；现在任何宽度下图标与温度都左右并排。
- 变更②（雾效果）：雾层由「9 个径向渐变雾团、雾/阴期间常驻」改为「高斯噪声雾、进入后约 4 秒淡出消散」。`frontend/src/components/SunLightLayer.vue` 用内联 SVG `feTurbulence(fractalNoise) + feGaussianBlur + feColorMatrix` 生成一张 320px 可无缝平铺（`stitchTiles`）的冷灰噪声图，三层不同颗粒尺寸（260/420/680px）与漂移周期叠加，`mask-image` 让雾底部浓、向上渐淡；动画只走 `transform/opacity`，纹理由浏览器栅格化一次后当背景图缓存（不引入 `filter: blur` 的周期性重栅格化）。淡入 0.6s、淡出 2.2s。
- 决策：雾层转瞬，压光与「进入 3 秒自动开灯补光」维持 V11.66 口径不变（天气本身仍是昏暗，灯亮后页面照常可读）；可见时长集中在 `useSunLight.js` 的 `FOG_VISIBLE_MS = 4000`，30 分钟一次的天气刷新会重播一次。VERSION 停在 V12.25（该号由另一并行会话的未提交改动占用，本次不重复递增）。
- 接口/表/路由：无变化。
- 踩坑：安卓壳（Capacitor WebView）没有 `setTextZoom`，会跟随系统「字体大小」放大网页文字——固定 px 的大号读数同样会被放大，单层 flex 换行就会把温度挤成上下排版；要防的是「读数行整体换行」，而不是禁止字号放大。
- 验证：`npm run lint` 0 error（另有他人未提交改动留下的 `AlbumDetail.vue` 1 条 unused warning，未触碰）；`npx vitest run` 1173 passed；`npm run build` 通过（`Weather` 懒加载 chunk 72.90KB / gzip 27.89KB、`useSunLight` 12.15KB / gzip 4.70KB）。
