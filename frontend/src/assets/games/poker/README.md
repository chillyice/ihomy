# 扑克牌面素材

| 项 | 值 |
|----|----|
| 来源 | 用户提供的本地高清牌面包 `高清全套扑克牌/PNG`(750×1044 PNG) |
| 本地位置 | `deck/*.webp`,240×334 WebP(质量 84),单张约 7–22KB,整套 418KB |
| 命名 | `<花色>-<点数>.webp`,花色 `S/H/C/D`,点数 `1–13`(A=1、J=11、Q=12、K=13);大小王为 `joker-small.webp`、`joker-big.webp` |
| 清单 | `deck.json`(id / suit / rank,含大小王) |
| 牌背 | 不用素材包里的 `Background.png`,沿用 `cards.css` 里跟主题走的 CSS 牌背 |

- 源图是带白底与圆角的整张牌面,直接按牌宽等比缩放,页面只用 `<img>` 铺满牌框,不再用 CSS 画点数和人头。
- 生成脚本:`scripts/art/build-poker-webp.py`(需要 Pillow),源目录可用参数覆盖。
- 许可:素材包未附许可声明,仅在本站家庭内部使用;若要对外分发,先确认牌面版权。
